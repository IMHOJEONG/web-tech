# Brotli CVE-2026-111497 기고 초안 준비

## Summary

사용자가 이번 글의 주제를 Brotli 취약점으로 확정해 공식 보안 공지와 수정 릴리스를 바탕으로 한국어 존댓말 초안을 준비했습니다. 공개일·확인일, 런타임 패치·패키지 갱신, WAF·외부 응답 경계를 나누고 로컬 검토를 준비했습니다.

## Changed

- [새 draft](../../../apps/docs/category/be/node-js/node-brotli-runtime-security.mdx): 정상 입력 .mts 두 조각과 실제 출력, 수정 버전·확인 절차를 포함합니다. 질문·퀴즈를 넣지 않았습니다.
- [개념도](../../../apps/docs/public/diagrams/node-brotli-waf-boundary.svg)와 PNG: 별도 입력 경로와 Vercel WAF 규칙 범위를 표현합니다.
- 로컬 실험실의 `brotli-article-source.json`, fixture·정식 테스트·전용 명령을 연결했습니다. 공개 본문에 실험실 이름·경로·검사 명령은 넣지 않았습니다.
- [검증 보고서](../../verification/content/2026-10-28-brotli-security-article.md), 실행 증거와 역할별 목차를 연결했습니다.

## Notes

기준 HEAD는 `61a778c5d7b083aec8bfd671c65523494921d5c9`이며 원래 `codex/squash-merge-preflight` 브랜치와 별도 ADR 거버넌스 미커밋 변경을 보존했습니다. 스테이징·커밋·푸시·운영 배포는 하지 않았습니다. 구조·공개 계약 변경이 없어 ADR은 추가하지 않았습니다.

원문/fixture의 타입·동작 검사 11개와 콘텐츠·네 화면 조건이 통과했습니다. 기존 TCP 글의 placeholder 경고와 초기 개발 이미지 캐시 표시는 보고서에 구분했습니다. 기술·독자 이해·존댓말 검토를 반영했습니다. 악성 PoC나 운영 패치 확인은 수행하지 않았습니다.

[KAN-44](https://web-tech-service.atlassian.net/browse/KAN-44)를 기존 이슈 검색 뒤 생성했으며, [기존 Confluence 운영 안내](https://web-tech-service.atlassian.net/wiki/spaces/~5d12f74be69c1c0c88af2afa/pages/65817/web-tech+Jira)에 로컬-only 검토 상태를 연결합니다. 초안 본문·화면·원시 로그는 외부에 올리지 않습니다. 기존 운영 패치 KAN-43과 분리합니다. 최종 기록 저장은 재조회로 확인합니다.

Confluence v175의 기존 운영 구역 보존과 KAN-44 연결을 재조회했습니다. Jira 기존 댓글 10035를 3열 표로 갱신해 댓글 총 1개·표·링크를 확인했고 검토 중 상태로 사용자 피드백을 기다립니다. 기록 대기나 도구 차단은 없습니다. 로컬 문서·원문은 원격에 게시하지 않았습니다.

### 사용자 검토 후 아키텍처 보강

단순 입력 경로 그림을 서비스·런타임과 배포 경로 두 장으로 확장하고 로컬 개발 서버 preview를 갱신했습니다. WAF·외부 응답·네이티브 디코더·CI·운영 프로세스의 경계를 나누고 그림 폭을 넓혔습니다. 최종 자산과 모바일/데스크톱·다크 모드·원문 11개 검사·다중 검토 결과는 위 검증 보고서의 후속 구역에 연결했습니다. 실행 코드는 변경하지 않았습니다. 후속 Confluence v178과 Jira 기존 댓글 10035의 3열 표·댓글 수 1을 재조회했습니다. 현재도 draft이며 스테이징·커밋·푸시하지 않습니다.

### 사용자 검토 후 버퍼와 원인 코드 보강

8바이트 고정 입력 버퍼와 정상/오류의 수정 전후 흐름 그림을 추가하고, upstream에 고정한 C·diff 발췌 여섯 개를 짧게 나눠 설명했습니다. MIT 원문을 함께 두었습니다. 실험실에 실제 MDX C 발췌의 소스 바인딩과 정식 검사 5개를 추가해 기존 정상 TS 검사를 포함한 16개를 통과했습니다. 부분 C는 읽기 전용 대조이며 공격 입력을 실행하지 않았습니다. 최종 네 화면 조건과 다중 검토 지적 반영, 초기 diff 공백 실패와 보완은 기존 검증 보고서의 후속 구역에 기록했습니다. Confluence v179와 Jira 기존 댓글 10035의 실제 3열 표·댓글 수 1·16개 검사 반영을 재조회했습니다. 현재도 draft·미커밋이며 다른 작업과 게시 글은 보존했습니다.

### 사용자 요청 후 서론·원인·대응·결론 재편집

보고서처럼 반복되던 구조를 독자가 따라갈 수 있는 흐름으로 정리했습니다. 비트 리더의 정상 버퍼 수명주기, 조건부 경계 밖 쓰기와 오류 반환 계약·디코더 결과 전파를 고정 원문에 근거해 보강하고, 코드·라이브러리에서 해제 경로를 찾는 방법을 추가했습니다. 기존 코드 조각·도식은 유지했습니다. 원문 연결 16개, 콘텐츠 검사와 네 화면 조건이 통과했고 기술·독자·어투 다중 검토를 반영했습니다. 상세 증거는 검증 보고서의 후속 구역에 있습니다. Confluence v183과 Jira 댓글 10035의 3열 표·댓글 수 1을 재조회했습니다. 사용자 검토 전 draft·미커밋 상태를 유지합니다.

### 참고자료·저작권과 초보자 재검토

다중 에이전트가 기술·독자 이해·존댓말과 권리 표기를 재검토했습니다. 공식·학습 자료 목록, 파일별 저작권과 프로젝트 MIT 라이선스를 명시하고 HTTP 압축 협상·실행 API·지원 종료 버전 설명을 보강했습니다. 앱 기고 지침에는 향후 새 글과 본문·예제 갱신 시 출처·저작권 고지 원칙을 추가했습니다. [검증 보고서](../../verification/content/2026-10-28-brotli-security-article.md)의 후속 구역에 16개 원문/예제 검사와 네 화면 조건, 기존 TCP 경고를 기록했습니다. Confluence v184와 Jira 댓글 10035의 3열 표·댓글 수 1을 재조회했습니다. 사용자 요청에 따라 스테이징·커밋·푸시·게시하지 않았습니다.

### 최신 main 기반 초안 미리보기

최신 main을 fetch하고 별도 detached 작업 트리의 3047 서버에 현재 draft의 복사본을 올려 diff 색상과 복사를 확인했습니다. 기존 브랜치의 고유 커밋과 미커밋 변경을 보존했고 기존 3001 서버도 그대로 두었습니다. 복사본은 이후 원본 수정과 자동 동기화되지 않습니다. 설치 및 최초 검사기의 실패와 최종 화면 조건은 [검증 보고서](../../verification/content/2026-10-28-brotli-security-article.md)에 구분했습니다. Confluence v191과 Jira 댓글 10035의 실제 3열 표·댓글 수 1을 재조회했습니다. 현재 브랜치 pull·병합·커밋·푸시·게시 없이 사용자 검토를 이어갑니다.

### 2026-10-29 기고 커밋 승인 후 재검증

사용자가 다른 미커밋 작업과 글 초안의 작업별 커밋을 승인했다. 최신 main `0da7979` 기반의 별도 작업 브랜치에 초안·도식·라이선스·이전 검증 증거를 복사하고 원본 파일은 유지했다. 본문 `status: draft`는 바꾸지 않는다. 원문 바인딩16개를 Node24.22.1에서 재실행해 실패/skip0을 확인했고 콘텐츠 메타·본문 규칙21파일과 검사기22개도 통과했다. 기존 TCP 게시본의 placeholder 경고는 이번 기고의 실패가 아니다. 기술·초보 독자·존댓말 읽기 전용 검토에서도 필수 수정이 발견되지 않았다. 출처·저작권 지침은 별도 커밋으로 분리했다. 새 운영·공격 차단·화면 검증을 수행한 것으로 과거 기록을 덮어쓰지 않는다. 이번에는 로컬 커밋만 수행하며 push·게시·배포는 하지 않는다.
