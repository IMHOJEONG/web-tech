# Docs 캐시 구조 설명 문서

## Summary

대화에서 설명한 캐시별 공유 범위와 실제 검색·게시 갱신 흐름을 별도 지식 문서로 정리했다.

## Changed

- [캐시 구조 설명](../../knowledge/content-platform/docs-cache-structure.md)에 범위 비교·인스턴스별 Map·검색 흐름·인증 웹훅의 Mermaid 그림을 추가했다.
- React 렌더 안의 재사용과 요청 간 Data Cache를 구분하고 로컬 재배포·NAS 게시 차이, TTL·브라우저 캐시 주의점을 기록했다.
- 기존 ADR·구현 코드·검증 보고서·절차를 연결하고 지식 목록과 월별 기록을 갱신했다. 앱 코드는 변경하지 않았다.

## Notes

이번 작업은 설명 문서 추가이며 기존 캐시 검증 결과를 새로 실행한 것으로 기록하지 않는다. 다른 미커밋 변경을 보존하고 구현 커밋과 설명 문서 커밋을 분리한다. 푸시는 후속 작업이다.

## Open Questions

실제 Vercel 게시 갱신과 배포 전후 cache key 검증은 기존 검증 보고서의 미완료 범위를 따른다.

## Next

운영 검증 결과가 생기면 검증 보고서를 갱신하고 이 설명 문서에서 연결한다.
