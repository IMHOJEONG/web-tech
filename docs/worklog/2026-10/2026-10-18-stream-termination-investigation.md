# CI 스트림 오류 8건의 원인 추적

## Summary

`f4b9582` CI의 스트림 조기 종료 8건과 로컬 재현을 분리해 조사했다. 진행 중인 관련 글 prefetch를 문서 이동으로 중단하면 같은 오류가 나는 것을 대조 실험으로 확인했다. 과거 CI 요청의 취소 주체를 소급 확정할 데이터는 없어 historical unknown을 유지한다.

## Changed

- 테스트 전용 Chromium 네트워크 계측으로 합성 상세 경로·요청 UUID·이동·취소 플래그를 연결했다. 진단 옵션 없이 실행할 때는 꺼진다.
- 루프백 콘텐츠 fixture에 인증된 본문 보류·해제를 추가하고, 진행 중 이동/서버 완료 후 이동의 두 회귀 조건을 만들었다.
- 스트림 메시지나 취소 단서가 실제 선행 오류를 가리지 않는 상태 판정 검사를 추가했다.
- [검증 보고서](../../verification/cache/2026-10-18-stream-termination-investigation.md), 정제 artifact 및 재현 runbook을 연결했다. 기존 TCP 초안·다이어그램은 변경하지 않았다.
- 후속으로 실제 메뉴·관련 글 Link 클릭과 동일 목적지의 문서 교체를 비교하는 검사를 추가했다. 테스트용 Link를 만들지 않고 앱의 실제 desktop 메뉴·mobile drawer·관련 글을 사용한다.
- 전체 검사에서 발견한 probe의 부분 JSON 읽기 경합은 같은 디렉터리의 임시 파일을 rename하는 원자적 교체로 보완했다. 목적지의 실제 로컬 카드도 확인한다.

## Notes

게시 갱신 진단 4개에서 오류 8건, prefetch 차단 비교군 4개에서 오류 0건. 대조·상태 판정은 첫 시도 36개 통과·2개 실패 후 관측/격리를 수정해 42개 통과했다. 실제 실행 명령과 제한은 검증 보고서에 모았다.

진단 옵션 없는 전체 production 회귀는 116개 통과 (1.1분)했다. 기존 구간 8회와 의도적 중단 검사 2회의 오류 로그 10회는 통과 여부와 별개로 남아 있다.

변경 TypeScript 5개 파일의 ESLint, docs 타입 검사, 문서 delta 검사, 변경 파일 Prettier와 diff 공백 검사가 통과했다. 기존 미커밋 23개 경로는 이번 README 항목을 제외하면 SHA-256이 동일하다. 커밋·푸시는 수행하지 않았다.

오류 메시지를 숨기거나 운영 prefetch를 끄지 않았다. 관측 범위가 partial이고 해당 Chromium terminal 이벤트가 없으므로 기계 판정을 정상 취소로 완화하지 않았다. 운영 장애가 없음을 일반적으로 보장하는 변경도 아니다.

### 실제 클릭 후속 비교

Link는 공유 문서를 유지하고, scheduler의 task 취소 표시가 곧 진행 중 fetch의 abort는 아니라는 설치 소스를 먼저 확인했다. 최초 12개 측정 후 결과를 고정해 36회 반복 통과했다. 문서 교체 12개는 오류가 났고 실제 메뉴·관련 글 클릭 24개는 오류 없이 서버 완료했다. 원래 prefetch와 별도의 전경 RSC가 있을 수 있어 단일 응답 재사용까지 주장하지 않는다. 조건과 정제 증거는 검증 보고서의 실제 Link 비교 절에 추가했다. 앱 UI·운영 동작·ADR 계약은 바꾸지 않았다.

목적지 카드까지 검사한 첫 전체 실행은 119개 통과·9개 실패했다. 존재하지 않는 Web 샘플 카드 기대값 8개와 JSON 덮어쓰기 경합 1개를 분리해 보완했다. 실패 중 발생한 fixture deadline 초과를 정상 취소로 처리하지 않았으며 세부 조건과 원본 해시를 보고서에 남겼다.

보완 후 전체 128개 통과 (1.4분), 의도적 문서 교체 등을 포함한 스트림 로그 14회는 그대로 유지했다. 실제 Link 비교의 stream error는 0회다.

최종 코드로 다시 36회 반복 통과 (1.2분)했고 결과는 동일했다. 추가·보완한 두 TypeScript 파일의 ESLint와 docs 타입 검사도 통과했다. 원래 미커밋 23개 경로는 이번 README 링크를 제외하면 기존 SHA-256과 동일하며 커밋·푸시는 하지 않았다.

## Open Questions

- Vercel 운영의 hook 오류를 실제 응답 종료와 안전하게 연결하는 ADR-0008 후속 범위는 미완료다.
- 과거 CI 8건의 상세 취소 신호는 보관되지 않았으므로 복원할 수 없다.

## Next

위 기록은 커밋 전 로컬 검증 결과다. 사용자 승인에 따라 계측·대조 `9a39901`, 이동 검사 분리 `b37adeb`와 조사 문서를 독립 커밋하고 `feature/docs`에 푸시해 CI를 확인한다. TCP 초안·도식·연결 기록과 해당 목차 항목은 제외한다. 전경 본문 실패나 선행 오류가 발견되면 prefetch 취소와 별도 장애로 추적한다.
