# TCP 캡처 로그 대조와 학습 개념 보강

## Summary

사용자가 관리자 권한으로 실행한 캡처와 소켓 결과를 대조했습니다.
HTTP·소켓 실행 성공과 패킷 증거 확보를 구분하고 기존 학습 문서에 해석 방법을 보강했습니다.
캡처 준비와 연결 시작을 조율한 최종 실행에서 실제 패킷과 종료 집계를 확보했습니다.

- 기존 소켓 초안에 실제 캡처 요약과 seq·ack 해석을 추가하고 로드맵 상태를 갱신했습니다.
  실행용 TypeScript 코드는 바꾸지 않았으며 글은 draft입니다.

## Notes

캡처 대기 도구의 패킷 없는 smoke는 종료 코드 0입니다. 실제 소켓 출력은 정상입니다.
두 번째 실행의 캡처 필터가 이전 서버 포트인 것을 직접 확인했습니다.
기술·초보자 이해 검토를 수행했고 FIN 방향과 절대 순서 번호 설명을 명확하게 했습니다.
수집 결과는 보고서에만 집계합니다. 실제 SYN·ACK 관측을 추정하지 않습니다.
최종 실제 패킷과 소켓 JSON을 프로그램으로 대조해 번호·길이·양방향 FIN 확인을 검증했습니다.
서비스 구조·공개 계약·공용 컴포넌트 책임은 바뀌지 않아 새 ADR은 작성하지 않습니다.
스테이징·커밋·푸시·게시를 수행하지 않았습니다.
