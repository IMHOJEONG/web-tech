# HTTP 학습 문서와 로드맵 재검사

## Summary

운영체제 통신 학습 문서와 학습 로드맵을 기술·초보자 이해·존댓말 관점에서
재검사했습니다. 용어와 실험 완료 조건을 보강하고, 최종 HTTP 초안의 원문 검사도
다시 실행했습니다. 커밋·게시하지 않았습니다.

## Changed

- [학습 문서](../../knowledge/infra-tooling/node-http-kernel-path.md): TCP·핸드셰이크·연결 재사용·TLS·종료 신호 설명,
  `highWaterMark`의 기준과 상한 구분, 참고 링크 문장과 실험 버전의 근거를 보강했습니다.
- [학습 로드맵](../../todo/todo.md#nodejs에서-운영-인프라까지-학습-로드맵): 기본 API와 정량 비교를 구분하고,
  사용자 검토 관문·제안 입력·반복 횟수·관측 단위·통과 조건을 명시했습니다.
  큰 표는 개요와 단계별 조건으로 나눴습니다.
- CPU 실험은 로컬 타이머로 확정 검사를 마련했고, 프록시 실험은 공통 시계·통제 버퍼로 제한했습니다.
  HTTP 경계 실험과 Next.js 첫 화면 실험의 범위를 줄여 후속 질문을 분리했습니다.

## Notes

- 세 에이전트의 지적을 반영했습니다. 기술·독자 재검토에서 남은 확실한 결함을 찾지 못했습니다.
  존댓말 검토의 모호한 청크 해제·테스트 신호 표현도 수정했습니다.
- Node.js v24.12.0·libuv·TCP/HTTP 공식 자료를 대조했습니다.
  RFC 9293 §3.7의 쓰기 경계 근거는 유효하며 §2.2도 함께 연결했습니다.
- 연결된 로컬 실험실의 최종 원문 코드 추출·strict 타입·HTTP 실행 검사 26개가 통과했습니다.
  현재 MDX SHA와 실행 로그의 SHA가 일치합니다. 과거 artifact는 당시 결과로 보존했습니다.
- [검사 결과와 범위](../../verification/artifacts/2026-10-10-http-learning-roadmap-review.json),
  [원문 테스트 실행 로그](../../verification/artifacts/2026-10-10-http-article-source-recheck.txt).
- 문서 구조·상대 링크·목차·로드맵 anchor와 필요한 파일의 포맷을 검사했습니다.
  로드맵 이전 TODO 영역은 포맷하지 않았습니다. 인덱스는 변경하지 않았습니다.
- Mermaid는 구조를 검토했으나 실제 렌더링은 이번 검사의 범위 밖입니다.
  앱 코드·본문 예제·그림을 수정하지 않아 새 화면/production/배포 검사는 수행하지 않았습니다.
  로드맵 신규 실험과 커널 계측은 여전히 미실행입니다.
- 학습 문서와 제안 조건의 정리이며 서비스 구조·공개 계약 변경이 없어 새 ADR은 추가하지 않았습니다.
