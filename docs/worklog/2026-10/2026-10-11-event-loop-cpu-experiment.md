# 이벤트 루프 CPU 실험과 학습 문서 반영

## Summary

사용자 요청으로 로드맵 4단계의 CPU 0/200ms 비교를 별도 송신·수신 프로세스에서 실행했습니다.
타이머·수신 콜백 지연과 본문 보존을 확인하고 실제 결과 그래프를 학습 문서에 연결했습니다.

## Changed

- 로컬 실험실에 `event-loop-cpu.mts`, 독립 송신자, 타입, 실제 실행 검사와 `/event-loop` 화면·API를 추가했습니다.
- [학습 문서](../../knowledge/infra-tooling/node-http-kernel-path.md)의 미실행 상태를 실제 관측과 구분해 갱신했습니다.
- [절차](../../runbooks/node-event-loop-cpu-observation.md), [결과·초기 실패](../../verification/content/2026-10-11-node-event-loop-cpu.md), 역할별 목차와 [로드맵](../../todo/todo.md#4-이벤트-루프)을 갱신했습니다.

## Notes

실제 조건별 3회·실패 사례·시작 시간 초과를 포함한 13개 검사가 통과했고 strict TypeScript 검사를 통과했습니다.
처음에는 긴 루프 지연 검사가 실패했습니다. 기준을 유지하고 예열 후 pre/post 샘플링으로 보강했습니다.
숫자·증거·한계는 검증 보고서를 원본으로 합니다. 커널 도착·HTTP/Next.js 서비스 성능은 미검증입니다.
3개 에이전트의 기술·독해·어투 검토를 반영하고 3뷰포트의 실제 API·그래프·표, 재시도와 403/409/405를 확인했습니다.
초기 화면 선택자 실패를 기록하고 모바일 도식의 가로축을 한 화면으로 재배치했습니다.
공개 글·운영 앱·공용 컴포넌트 계약을 변경하지 않아 새 ADR 대상이 아닙니다.
사용자 지시대로 커밋·푸시·게시하지 않았습니다. 기존 스테이징과 다른 작업의 변경은 유지합니다.
