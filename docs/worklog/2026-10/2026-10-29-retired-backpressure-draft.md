# 게시본과 중복된 옛 백프레셔 초안 정리 기록

## Summary

2026-10-01에 시작한 초안의 과거 작성·검토 기록과 10-29의 중복 정리 결과를 구분해 보존했다. 실제 공개 글은 이미 published이며 이 기록 이관으로 옛 초안을 다시 게시하지 않는다.

## Changed

- 사용자 승인으로 옛 미추적 MDX를 당시 main `0da7979`의 같은 경로 게시본과 대조한 정리 이력을 분리했다.
- 목차 12개와 JS 예제 3개의 대조에서 게시본의 TypeScript 타입을 제거한 코드가 같았고, 나머지는 방향 표현·TypeScript 실행 안내·출력 설명의 편집 보강이었다.
- 옛 초안은 앞선 승인 단계에서 제거하고 원문 SHA-256 `c8cc89bf7c2b06afa51bf8da915130343335518cc3ea3dabf7cd5b2663d2fd30`과 같은 비공개 사본을 남겼다. 이번 커밋에는 그 원문이나 미승인 초안을 넣지 않았다.

## Notes

[KAN-51](https://web-tech-service.atlassian.net/browse/KAN-51) 전체 작업 트리 정리에서 남아 있던 초기 worklog의 작성 당시 상태와 위 정리 이력을 대조했다. 초기 draft 상태를 현재 게시 상태로 오해하지 않도록 정제한 기록만 별도 커밋으로 분리했다. 원래 상세 기록은 비공개 사본에 남겼으며 현재 게시본이나 기고·검증 이력은 수정하지 않는다.
