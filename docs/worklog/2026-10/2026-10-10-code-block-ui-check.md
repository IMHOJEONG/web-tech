# 코드 접기 커밋과 UI/UX 점검

## Summary

사용자가 확인한 코드 접기·컴팩트 조작 영역을 `ec1e210`으로 커밋한 뒤 항목별 UI/UX를 점검했다. 영어 복사 문구와 작은 화면의 확대된 하단 정보 겹침을 확인했고, 후속 요청에 따라 두 문제를 작업 트리에서 수정했다.

## Changed

- 이전 코드 접기 구현·관련 테스트·본문 출력 계약만 선별 커밋했다. HTTP 초안·도식·개발 미리보기와 다른 작업은 제외했다.
- `apps/docs/scripts/check-code-block-usability.ts`: 수정 전 커밋 CSS 및 수정 후 작업 트리 CSS의 3개 브라우저 matrix, 선택적인 로컬 개발 페이지 점검.
- [검증 보고서](../../verification/accessibility/2026-10-10-code-block-usability.md)에 재현 명령·범위·실패 조건·원본 증거를 연결했다.
- 검증·증거·월별 목차에 이번 결과를 추가했다. 후속 승인에 따라 코드 수정과 관련 검사·문서만 선별 커밋한다.
- 로컬·원격의 복사 문구·접근성 이름을 공통 locale 규칙으로 맞췄다. 기본·성공·실패·복구 상태를 검사한다.
- 하단을 가변 높이 grid/flex로 구성하고 줄 수 nowrap을 제거했다. native details와 전체 복사는 유지한다.
- 기존 브라우저 점검 문서에 W3C 근거, 글자 200%·320 CSS px reflow·실용적인 축소 범위와 수동 점검을 추가했다.
- 125·150%를 추가한 수정 후 측정값과 캡처는 별도 파일로 보관한다. 상세 결과는 검증 보고서에만 유지한다.

## Notes

기존 E2E와 matrix·실제 개발 페이지의 결과는 검증 보고서에 유지한다. 개발 서버는 사용자가 확인하도록 3001 포트에 남겨 두었다. 첫 점검 당시에는 푸시하지 않았으며, 후속 사용자 요청에 따라 `feature/docs`로 푸시하고 커밋된 소스를 임시 디렉터리에서 다시 검사한다. 다른 작업의 미커밋 파일과 섞인 문서 목차·CSS·정책은 이번 작업 부분만 선별한다.

## Open Questions

실제 모바일 기기의 글자 확대와 스크린리더에서 같은 구조가 잘 읽히는지 후속 확인이 필요하다.

## Next

실제 브라우저 zoom 200·400%와 축소 80·90%, 실기기 글자 크기 설정을 확인한다. CI 완료·배포 검증은 로컬 검사와 구분한다. 기존 계약의 보완이므로 새 ADR은 만들지 않았다.
