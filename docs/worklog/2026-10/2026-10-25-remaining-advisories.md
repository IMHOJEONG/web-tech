### NAS 이미지 적용 후 확인

다음은 2026-10-25의 후속 관측입니다. 당시 이미지와 교체 안내는 역사적 기록이며 현재 배포·rollback 권고가 아닙니다. 2026-10-29에는 보존된 이 구역만 이식했고 새로운 원격 조회·NAS 변경·운영 검증은 하지 않았습니다. 이후 관측을 이 과거 결과로 덮어쓰지 않습니다.

사용자가 NAS 이미지 교체와 `latest`·빈 revision·`healthy` 조회 결과를 제공했다. 외부 인증 경계·목록 schema·공개 본문·캐시 헤더를 읽기 전용으로 확인하고 [검증 보고서](../../verification/security/2026-10-25-remaining-advisories.md#nas-적용-후-외부-재검증)에 추가했다. 실행 이미지 digest 대조 전까지 운영 패치 적용은 미확인으로 유지한다. 외부 health 200은 내부 전용 정책과 차이가 있어 별도 후속으로 남기며 NAS·프록시 설정은 변경하지 않았다. 같은 KAN-35와 Confluence에 사실·한계를 연결하며 문서 변경은 로컬에만 남긴다.

사용자가 추가로 전달한 필드 없는 해시와 기대 게시 이미지의 config digest가 다름을 registry 원본에서 확인했다. `id`·`RepoDigests`의 라벨 포함 전체 출력을 재요청했고, 다른 이미지 실행으로 단정하지 않는다. 실제 해시와 재현 명령은 검증 보고서에만 둔다.

후속 라벨 포함 출력에서 실행 config ID와 `digests=[]`가 확인됐다. 검증한 게시 이미지와 다른 실행 이미지로 판정하되 패치 누락·취약점 존재로 확대하지 않는다. 운영자가 기존 백업·환경·볼륨·프로젝트를 유지하며 검증한 immutable 이미지로 교체한 뒤 재확인하도록 안내한다. 에이전트의 NAS 설정 변경·pull·재기동은 없다.

재교체 후 제공된 실행 config ID와 RepoDigest가 기대 게시본과 모두 일치해 이미지 적용을 확인했다. 외부 API 재검증은 인증경계·schema·캐시 정책 정상이나 문서가 1개에서 0개로 바뀌어 콘텐츠 정상화는 미완료다. 상세 표본도 없어 재교체 후 본문은 미검증이다. 의도적 문서 제거 여부와 컨테이너 내 Markdown 파일 개수만 재요청했으며 원인·healthy를 추정하지 않는다. NAS 파일·설정 변경은 하지 않았다.
