# 문서 인덱스와 검색 결과의 목록 우선 배치

## Summary

검색·접이식 필터·현재 선택 다음에 실제 문서 목록을 표시하도록 구현했다. 모바일 첫 제목 위치가 로컬에서 인덱스 512px·검색 452px임을 확인했다. 공개 배포는 미검증이다.

## Changed

- `DocsIndex`의 인덱스·검색 공통 레이아웃을 통합하고 보조 탐색을 목록 뒤로 옮겼다.
- 검색 패널을 간결하게 만들고 필터는 기본 접힘으로 제공한다. 활성 선택·개별 해제와 추천 검색어를 작은 서버 컴포넌트로 분리했다. 한/영 문구를 추가했다.
- 목록 순서·위치·선택 해제 E2E와 기존 내비게이션 검사를 보완했다. 카드·검색 순위·데이터 조회 계약은 유지했다.
- [로컬 검증 보고서](../../verification/accessibility/2026-10-19-docs-index-order-local.md), [정책](../../architecture/docs-search-experience-policy.md#문서-목록-순서와-밀도-보완-검토)과 TODO에 상태를 반영했다.

## Notes

타입 검사·lint, 관련 E2E 69개(5개 조건부 제외), 캡처 옵션 보완 후 목록 12개와 추가 화면 26조건이 통과했다. 첫 실행의 caret-color hydration 경고와 환경 한계는 검증 보고서에 남겼다. 구현·검증 시점에는 커밋·푸시하지 않았으며, 10-19 후속 요청에 따라 목록 개선과 스켈레톤을 독립 커밋으로 묶어 main 대상 PR을 준비한다. 기존 TCP 초안·도식·관련 증거는 게시 승인 전 보존 작업이므로 제외한다.

## Open Questions

목록 뒤의 통계·섹션 카드 내용을 얼마나 줄일지와 태그·모음의 추가 접힘 방식은 다음 단계에서 화면을 보며 정한다. 운영 배포와 실제 사용자 탐색 효과는 아직 확인하지 않았다.
