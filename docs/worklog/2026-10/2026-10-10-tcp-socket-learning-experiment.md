# 소켓 끝점 학습 실험과 운영체제 관측

## Summary

로드맵 3단계의 소켓 실험을 실행하고 검토용 초안 한 편을 만들었습니다.
Node.js의 양쪽 끝점과 macOS의 소켓 상태를 대조했습니다.
패킷 캡처는 OS 권한 제약으로 미완료이며 재실행 절차를 준비했습니다.
후속 요청으로 기존 로컬 실험실의 화면에서도 이 예제를 실행하도록 연결했습니다.

## Changed

- 새 `.mts` 예제·5분할 코드·요청/응답 구조 그림을 포함한
  [소켓 초안](../../../apps/docs/category/be/node-js/tcp-socket-endpoints-lab.mdx)을 추가했습니다.
- 기존 로컬 실험실에 독립 원문 바인딩·strict 타입·반복·음성 검사를 연결했습니다.
  기존 HTTP 바인딩은 유지했습니다. 공개 본문에 실험실 경로를 노출하지 않았습니다.
- [학습 문서](../../knowledge/infra-tooling/node-http-kernel-path.md),
  [로드맵](../../todo/todo.md#nodejs에서-운영-인프라까지-학습-로드맵)의 실행 상태를 갱신했습니다.
- [소켓·패킷 재현 절차](../../runbooks/node-tcp-local-observation.md)와
  [관측 보고서](../../verification/content/2026-10-10-node-socket-kernel-observation.md)를 작성했습니다.

- 로컬 실험실의 `/sockets` 화면·고정 스크립트 실행 API·메인 링크와 README를 추가했습니다.
  실험실 브라우저 연결과 실제 관측 연결을 구분하고 기존 `.mts`를 재사용했습니다.

## Notes

새 글의 fixture와 실제 MDX 각각 3회, strict 타입과 음성 검사 11개 통과.
기존 HTTP 원문 회귀 14개·콘텐츠 19개·문서 검사도 통과했습니다.
세 에이전트의 지적을 반영했습니다. 개발 서버 3개 폭에서 실제 본문·그림을 확인했습니다.
본문에 쓴 과거 실행 발췌와 최종 원문 SHA 검사는 분리해 보관합니다.
자세한 증거와 미검증 항목은 보고서에만 집계합니다.
추가한 실험실 화면의 3개 폭 실제 API·본문·오류 처리 검사와 전체 타입 검사도 통과했습니다.
초회 정상 요청 403은 Next 내부 hostname 비교를 실제 Host 기준으로 수정해 해결했습니다.
운영 서비스·공개 콘텐츠 계약은 바꾸지 않았습니다. 로컬 전용 관측 실행기 추가이며
배포나 공용 컴포넌트 정책 결정이 아니므로 새 ADR은 필요하지 않습니다.
전체 포맷이나 다른 작업 변경의 스테이징·커밋·게시를 수행하지 않았습니다.

## Open Questions

SYN·ACK 실측은 사용자의 로컬 관리자 인증이 필요합니다. 기존 OS 보호 설정은 변경하지 않습니다.
