# 운영체제 통신 학습 문서와 단계별 로드맵

## Summary

HTTP 클라이언트와 서버 사이의 커널 경로를 학습 문서로 정리하고,
한 질문·한 실험·사용자 검토로 깊이를 쌓는 로드맵을 기존 TODO에 추가했습니다.
현재 HTTP 초안에는 선택형 설명을 연결했습니다. 커밋·게시하지 않았습니다.

## Notes

- 기술·초보자 이해·존댓말 검토를 수행하고 지적을 반영했습니다.
  CPU 실험은 별도 송신 프로세스로 생산자 지연을 분리하고 콜백 실행까지만 관측합니다.
  Node.js 대기량 제어와 TCP 윈도우·커널 큐 관측을 별도 검증으로 분리했습니다.
  공개 설명의 준비 상태 API 이름·CPU 지연 설명은 덜고 학습 문서의 후속 단계로 남겼습니다.
- 연결된 로컬 실험실의 원문 바인딩·strict 타입·HTTP 회귀 테스트 26개가 통과했습니다.
  실제 HTTP 실행은 21회입니다. 실행 후 설명문만 검토 수정했으므로 실행 당시와 최종 원문 SHA는 구분했습니다.
- 앱 단위 검사 4개와 콘텐츠 18개 검사가 통과했습니다. 실제 개발 서버에서
  1280px·670px·390px의 신규 details 열기·닫기, 5단계 표·한계 표시, 기존 4개 도식·취소 코드 펼쳐보기를 확인했습니다.
- [검증 증거](../../verification/artifacts/2026-10-09-http-kernel-learning.json),
  [개발 서버 화면](../../verification/artifacts/2026-10-09-http-kernel-learning-desktop.jpg).
- 변경 문서의 상대 링크·구조 검사와 필요한 파일의 포맷 검사, diff 검사가 통과했습니다. 인덱스는 변경하지 않았습니다.
- 커널 내부·패킷 관측 및 로드맵의 신규 실험은 미실행입니다. 현재 검사는 개발 환경이며 배포 검증은 아닙니다.
  학습 자료 정리로 서비스 구조·데이터 흐름·공개 계약·공용 컴포넌트 책임은 바뀌지 않아 새 ADR은 추가하지 않았습니다.
