# PR #47 Jira·Confluence 연결과 매 작업 기록 기준

## Summary

[PR #47](https://github.com/IMHOJEONG/web-tech/pull/47)의 운영 전환 기록을 Jira와 기존 Confluence 개발·운영 안내에 연결했다.
사용자 요청에 따라 이후 실제 작업마다 두 도구에 기록을 남기는 공통 절차를 로컬 지침에 반영했다.

## Changed

- 중복 검색 뒤 KAN-1 하위에 [KAN-14](https://web-tech-service.atlassian.net/browse/KAN-14)를 등록하고 PR 검토 상황에 맞춰 검토 중으로 전환.
- [Confluence 개발·운영 안내](https://web-tech-service.atlassian.net/wiki/spaces/~5d12f74be69c1c0c88af2afa/pages/65817/web-tech+Jira)에 매 작업 기록 절차와 PR #47의 근거 입구를 갱신.
- 초기 PR 본문에 Jira·Confluence 링크, 완료 조건·남은 main 병합/배포 확인을 연결. 당시에는 소스 커밋을 바꾸기 위한 push를 수행하지 않았으며, 이후 별도 승인으로 공통 지침 커밋을 분리해 전달.
- 루트 `AGENTS.md`, [이슈 추적 규칙](../../process/issue-tracking.md), [문서화 운영 규칙](../../process/codex-documentation-policy.md), PR 템플릿에 시작·검증·마감 시 기록과 실패 대응을 추가. `CLAUDE.md`는 기존대로 루트 지침을 참조.
- 후속 사용자 승인으로 Jira 진행·마감 댓글의 `항목 | 상태 | 결과 및 남은 작업` 3열 표 형식을 공통 기준에 추가하고, 공통 지침·템플릿·해당 기록만 초안과 분리해 PR #47로 전달.

## Notes

Jira는 상태·완료 조건의 원본, Confluence는 맥락·지식의 입구, 저장소는 기술 결정·절차·검증 증거의 원본으로 유지한다.
같은 작업의 작은 수정마다 새 티켓·페이지를 만들지 않고 기존 기록을 갱신한다.
이번 변경은 연결 도구 기반의 작업 절차이며 GitHub for Atlassian 설치·백그라운드 동기화·예약 실행을 설정한 것이 아니다.

PR head `c99cf2c2aec4e0a7bea982e465710cec3f85f262`의 성공 검사 22개는 기존 원격 커밋의 결과다.
초기 공통 지침·템플릿 변경은 로컬-only였으며 해당 CI가 새 변경까지 검증한 것으로 표시하지 않는다. 후속 지침 커밋의 원격 CI는 별도 SHA에서 확인한다.
이 작업의 변경 문서·포맷·고신뢰 비밀정보 패턴 검사는 통과했다. 기존 미커밋 초안을 포함한 작업 트리 검사이며 실제 신규 변경은 공통 지침·템플릿·기록 6개 파일로 한정했다.
초기 연결에서 Confluence version 2의 기존 표·보류 안내 보존과 신규 PR/Jira 링크, Jira의 PR Web link·Confluence native backlink를 재조회했다.
PR 설명의 상호 링크와 source SHA 불변, 기존 22개 check 성공을 확인했다. Jira에는 마감 댓글을 남기고 main 병합 전이므로 검토 중 상태를 유지했다.

후속 가독성 요청으로 기존 Jira 댓글 `10003`을 항목·상태·결과 및 남은 작업의 3열 표로 정리했다. 기존 링크와 검증 기준·미커밋·미검증 구분을 유지하고 재조회에서 표 저장과 댓글 총 1개를 확인했다. 내용·상태 변경 없는 형식 수정이므로 새 댓글·이슈·Confluence 버전은 만들지 않았다.

공통 지침 커밋은 PR #47 브랜치의 임시 작업 트리에서 분리한다. 새 작업 기록의 목차 항목만 옮기며 비공개 TCP 글·첨부·검증 자료와 별도 정리 기록은 포함하지 않는다. 원래 초안 작업 트리·스냅샷은 유지한다.
Jira·Confluence에는 배포 기준 전환 → 동일 소스 검증 → 기존 브랜치·원본 stash 정리 → 도구 상호 연결 → 공통 지침·표 형식 반영 순서로 요약하고, 커밋·푸시와 main 병합·후속 운영 검증을 구분한다.

현재 비공개 TCP 초안과 새 main 기준 스냅샷은 유지한다. 외부 기록에는 초안 본문·첨부·토큰·쿠키·원시 인증 응답을 포함하지 않는다.
담당자·기한·스프린트·공간 권한은 변경하지 않았다.

## Open Questions

PR #47의 새 공통 지침 커밋에 대한 CI·리뷰와 main 병합 시점. 병합 이후 자동 배포 확인은 별도 승인·검증 대상이다.

## Next

이후 작업부터 기존 이슈 검색 → Jira 작업/상태 갱신 → Confluence 요약·원본 링크 갱신 → PR 상호 연결 → 저장 결과 재조회 순서로 진행한다.
기록 도구 오류가 있으면 로컬 worklog와 최종 답변에 미기록 항목을 남기고, 완료나 자동 동기화 성공으로 추정하지 않는다.
공통 지침을 커밋할 때는 비공개 초안과 분리하며, 초안 항목이 섞인 목차를 전체 add하지 않는다.
