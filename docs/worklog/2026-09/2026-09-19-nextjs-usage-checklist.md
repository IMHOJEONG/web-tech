# Next.js 활용 점검 기준 정리

## Summary

기능 도입 개수가 아니라 정확성·보안·성능과 재현 가능한 증거로 Next.js 활용을 평가할 체크리스트를 작성했다.

## Changed

[점검 체크리스트](../../runbooks/docs-nextjs-usage-checklist.md)에 서버 경계, 캐시, 장애, 스트리밍, SEO, 리소스, 접근성, 관측 기준과 시작 명령을 정리했다. runbook 및 월별 목차를 연결했다.

## Notes

로컬 Next.js 16.3.4와 주요 코드 구성을 확인하고 공식 가이드를 참조했다. 전체 항목을 실제 검증한 것은 아니므로 체크박스는 미완료 상태로 유지했다. 앱 코드, Git 기록, 운영 환경은 변경하지 않았다.

## Open Questions

배포별 캐시 신선도와 실사용 성능은 별도 검증이 필요하다.
