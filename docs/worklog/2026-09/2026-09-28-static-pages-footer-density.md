# 안내 페이지와 푸터 링크 밀도 조정

## Summary

Privacy·Terms·Changelog를 읽기 쉬운 크기로 줄이고, 데스크톱 푸터의 유틸리티 링크 간격을 좁혔다.

## Changed

- 공통 `StaticPage`의 상단 여백, 본문 폭, 제목 크기를 줄이고 세 섹션을 큰 카드 대신 구분선 목록으로 표현했다.
- 푸터 링크 간격을 줄이되 각 링크의 최소 높이 44px를 유지했다.
- 세 페이지의 반응형 레이아웃을 확인하는 E2E를 추가했다.
- 내용과 연결 대상이 일치하지 않던 보조 박스를 세 페이지에서 제거하고, 단일 열 본문으로 정리했다. 더 이상 사용하지 않는 한·영 보조 박스 문구도 삭제했다.

## Notes

- 로컬 Chromium 모바일 390px, 태블릿 768px, 데스크톱 1280px에서 세 페이지 E2E 9개가 통과했다. 세 화면에서 가로 넘침은 없었다.
- 스크린샷으로 Privacy의 모바일·데스크톱 배치를 확인했다. 실제 운영 배포 화면과 다른 브라우저는 아직 확인하지 않았다.
- 공통 콘텐츠 구조와 URL, 메타데이터는 변경하지 않았다. 기존 ADR의 책임 경계 변경도 없다.
