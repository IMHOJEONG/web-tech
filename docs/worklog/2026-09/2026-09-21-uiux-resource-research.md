# UI/UX 자료 조사

## Summary

UI/UX 탭에서 개발자가 얻을 수 있는 정보를 구체화하기 위해 WAI, MDN, GOV.UK, Playwright, NN/g의 원문을 조사했다. 화면 구현이나 공개 글 발행은 진행하지 않았다.

## Changed

- [UI/UX 조사 문서](../../knowledge/docs-app/uiux-resource-research.md)에 주제 우선순위, 출처, 첫 포커스 심화 글의 실험 계획과 목록·상세 UI 후보를 정리했다.
- 자료가 없는 예시 카드 대신 실제 문제와 결과물을 설명하는 목록을 제안했다.
- 모달/비모달 구분, 라이브러리별 복귀 처리, 자동 접근성 테스트의 한계를 명시했다.
- 기존 설계 결정을 대체하지 않는 조사 단계다. 구현 방향을 확정할 때 관련 정책·ADR과 조정한다.

## Notes

2026-09-21에 공식 문서와 원저자 UX 자료를 열어 확인했다. 출처 링크는 조사 문서의 해당 주장 옆에 배치했다. 실제 라이브러리 동작 실험, 사용자 조사, 화면 비교 테스트는 실행하지 않았으며 그 결과를 추정하지 않았다.

## Open Questions

첫 심화 글의 재현 대상 라이브러리·버전과 수동 검증 환경을 확정해야 한다. 기존 포커스 글을 보강할지 별도 심화 글로 연결할지도 구현 전에 결정한다.

## Next

포커스 문제 하나의 최소 재현과 검증을 먼저 진행한다. 검수 후 실제 공개 자료만으로 UI/UX 목록 개편 범위를 결정한다.
