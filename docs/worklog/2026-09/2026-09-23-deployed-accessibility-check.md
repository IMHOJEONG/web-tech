# 배포 접근성 후속 점검

## Summary

본문 바로가기 개선 이후 운영 사이트를 검사했다. 키보드 이동은 통과했으나 새 포커스·색상 CSS가 배포 응답에서 누락된 점을 발견했다.

## Changed

[검증 보고서](../../verification/accessibility/2026-09-23-deployed-shell.md)와 테스트 결과를 추가했다. 앱 코드·배포·캐시는 변경하지 않았다.

후속으로 로컬 production 빌드와 브라우저 검사를 실행해 보고서에 비교 결과를 추가했다. 이 과정에서는 로컬 `.next` 빌드 산출물이 갱신됐으며, 앱 소스와 운영 배포는 변경하지 않았다.

## Notes

Chromium 16개 통과·4개 실패·4개 조건부 제외, Firefox·WebKit 8개 조합 통과. 실패 이후 실행되지 않은 대비 검사는 통과로 기록하지 않았다. 실제 스크린 리더 낭독은 미검증이다.

로컬 production 후속 검사에서는 Chromium 20개 통과·4개 조건부 제외로, 운영에서 실패한 4개 검사도 통과했다. 새 CSS 토큰과 실선 포커스 계산값을 확인했다. 기존 로컬 빌드 캐시는 삭제하지 않았다.

## Open Questions

GitHub 배포는 성공했지만 공개 CSS에 새 규칙이 없는 원인은 아직 확정하지 못했다. 기존 Obsidian 문서 변경은 보존했다.
