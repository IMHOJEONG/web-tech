# 문서 역할별 분리

## Summary

검증 보고서와 구현 작업 기록을 분리하고 작업 기록을 월별로 정리했다. 블로그 공개 콘텐츠와 애플리케이션 코드는 변경하지 않았다.

## Changed

- 검증 중심 보고서 5개: `docs/verification/performance`, `docs/verification/cache`로 이동.
- 측정 JSON 6개: `docs/verification/artifacts`로 이동.
- 기존 작업 기록 166개: `docs/worklog/YYYY-MM`으로 이동.
- 루트·설계·운영·검증·월별 작업 기록 목차 및 역할별 작성 규칙 추가.
- 저장소 내 참조 경로와 이동 문서 내부 상대 링크 갱신.

## Notes

미커밋 문서도 현재 내용을 기준으로 이동했다. 삭제나 재작성으로 사용자 수정 내용을 되돌리지 않았다. 이동 전후 링크를 비교하여 새로 발생한 링크 오류가 없는지 확인했다. 기존의 다른 앱·CI·테스트 변경은 그대로 유지한다.

검증 결과:

- 이동 대상 177개 모두 새 위치 존재, 이전 위치 잔존 없음.
- 저장소 텍스트 파일에서 이전 파일 경로 참조 0개.
- 경로 및 링크 목적지를 제외한 이동 문서 본문 차이 0개.
- 새 목차를 포함한 docs 내부 Markdown 링크의 대상 파일 확인.
- `git diff --check` 통과.
- 문서 재분류만 수행했으므로 앱 빌드와 운영 성능 측정은 재실행하지 않음.

## Open Questions

과거 문서에 이미 존재하던 잘못된 링크는 별도 정리가 필요할 수 있다. 외부 공유된 예전 GitHub 경로는 저장소 내부 치환만으로 자동 이동되지 않는다.

## Next
