# 상세 요청의 로컬 문서 중복 읽기 제거

## Summary

상세 문서 선택과 관련 문서 목록 생성에서 같은 로컬 파일을 두 번 읽는 문제를
실측하고 React 요청 단위 cache로 공유했다.

## Changed

- 로컬 파일 읽기·frontmatter 파싱 결과를 RSC 요청 안에서 공유한다.
- 내부 배열 freeze, 호출자 배열 복사, 비파괴 정렬로 공유 상태의 변경을 방지한다.
- 테스트 전용 I/O probe와 연속 요청 회귀 검사를 추가했다.
- [운영 절차](../../runbooks/docs-article-streaming-performance.md)와 서버 렌더링 정책을 갱신했다.

## Notes

수정 전 파일당 두 번 읽기가 검출됐고 수정 후 요청당 한 번으로 줄었다.
전체 24개 테스트와 lint를 통과했다. [검증 보고서](../../verification/performance/2026-09-19-local-document-reads.md)에 횟수와 한계를 기록한다.
원격 우선 선택·TTL·웹훅 계약, prefetch 취소 로그는 변경하지 않았다.

## Open Questions

후속 점검에서 테스트를 언어·문서 종류·동시 요청으로 확장했고 전체 36개를 통과했다.
관련 문서/이어 읽기의 입력 비변경 검사를 포함한 단위 테스트 9개도 통과했다.
현재 공유 객체 변경은 발견하지 않았고, 장래 readonly 타입 계약 도입은 별도 개선 후보다.

검색·카테고리 파서는 정규화 정책이 일부 달라 별도 통합 검토가 필요하다.
