# 공용 문서 미리보기 카드 도입

## Summary

피드 화면 적용과 분리해 문서 entity의 재사용 가능한 카드 표현을 먼저 도입한다.

## Changed

- `DocumentPreviewCard`는 제목·요약·주제·썸네일과 단일 상세 링크를 표시한다.
- `DocumentCardMeta`는 작성자와 번역된 읽기 시간 문자열을 표시한다.
- 기존 `DocumentThumbnail`과 디자인 토큰을 재사용한다.
- 제목 단계와 이미지 최적화 옵션은 호출자가 지정하며 데이터 조회와 필터에는 의존하지 않는다.
- 단일 링크와 focus ring을 사용하고 이미지 높이는 최대 192px로 제한한다.

## Notes

이 커밋은 컴포넌트 정의만 추가하며 기존 화면은 변경하지 않는다.
로컬 피드에 적용한 작업 상태에서 타입·린트 및 브라우저 검사를 수행했으며,
통합 테스트와 결과 기록은 이어지는 피드 적용 커밋에 포함한다.
