# 공개 콘텐츠 독해 검토

## Summary

공개 로컬 글 10개를 제목·설명 흐름·용어·예제·결론 기준으로 읽고 편집 우선순위를 정했다.

## Changed

[검토 보고서](../../verification/content/2026-09-20-content-readability-review.md)와 작성 정책의 독해 기준을 추가하고 TODO에 후속 편집을 기록했다. 원문은 변경하지 않았다.

## Notes

추가 문장 검토에서 포커스 순환의 모달 범위, endpoint/UI fallback 구분, Client Component의 최초 HTML 렌더링 설명을 보완할 대상으로 기록했다. WAI-ARIA와 Next.js 공식 문서로 해당 설명을 대조했으며, 원문은 수정하지 않았다.

실제 독자 테스트나 브라우저 시각 검증이 아닌 원문 편집 검토다. 앱 코드 변경이 없어 앱 테스트는 재실행하지 않았다.

Canvas 본문과 연결된 데모의 크기·좌표 변환 차이, 이벤트 루프 checkpoint 설명, 프로세스 간 공유 메모리의 예외를 추가 검토했다. WHATWG·Chrome·Microsoft 공식 자료를 근거로 보고서에 보완안을 기록했다. 실험 브라우저 실행은 하지 않았고, 글 원문과 앱 코드는 변경하지 않았다.

후속 Canvas 보완에서는 글의 크기·변환 행렬·지원 검사·단일 paint 등록을 적용하고 재현 조건을 추가했다. 앞선 원문 미수정 기록은 검토 단계의 상태이며, 이번에는 Canvas 글만 수정했다. 예제 추출 테스트 4개와 콘텐츠 테스트 17개가 통과했다. 명령과 검증 한계는 [검토 보고서](../../verification/content/2026-09-20-content-readability-review.md#canvas-보완-및-예제-검사)에 기록했다.

실제 Chrome 153 별도 테스트 창에서 Canvas 본문 예제와 데모의 픽셀 출력·버튼 경계·클릭·hover를 검증했다. 최종 검사에서는 두 페이지 모두 통과했고 pageerror는 없었다. 실행 스크립트·JSON·스크린샷과 초기 hover 측정의 한계를 [검증 보고서](../../verification/content/2026-09-20-content-readability-review.md#canvas-실제-브라우저-후속-검증)에 추가했다. 글의 미검증 안내도 실제 확인 환경과 남은 미검증 범위로 갱신했다.

## Open Questions

저장한 브라우저 스크립트 재실행에서는 hover 유지 실패와 대기 시간 초과로 종료 코드 1이 발생했다. 앞선 1회 통과를 전체 완료로 해석하지 않도록 실패 JSON을 별도 보관하고 보고서·글에 반복 안정성 미확인을 명시했다. 그리기·클릭 성공 사례와 hover 실패를 구분하며 창 포커스 또는 실험 API 중 원인은 미확정이다.

입문 설명과 경험자용 점검 노트 중 각 글의 대상 독자를 확정해야 한다.
