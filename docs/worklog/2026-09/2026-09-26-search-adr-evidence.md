# 검색 ADR에 배포와 검증 근거 연결

## Summary

4번 검색 이동 통일을 `d7305af`로 커밋한 뒤 5번을 진행했다. ADR-0007의 오래된 “작업 트리 반영” 상태를 구현 커밋·배포 성공 기록·공개 화면 관측으로 나누어 갱신했다.

## Changed

- [ADR-0007](../../architecture/adr-0007-search-input-contract.md)과 설계 목차에 확인한 적용 범위를 연결했다. 입력 계약의 결정·대안은 변경하지 않았다.
- 이전에 언급한 14개 통과의 저장소 원본을 찾지 못해 현재 공개 사이트를 새로 검사했다. [검증 보고서](../../verification/content/2026-09-26-deployed-search-contract.md)에 검색 6개·About 8개, 실행 명령과 추출 artifact를 구분해 남겼다.
- 새 검색 이동 개선은 로컬에만 있으므로 운영 통과 대상으로 표시하지 않았다. 다른 미커밋 계측·사용자 변경은 그대로 보존했다.

## Notes

공개 페이지 검사와 GitHub deployment 조회는 읽기 전용으로 수행했다. push·재배포·캐시 갱신은 하지 않았다. 이번 5번 문서 변경은 미커밋 상태다.

## Open Questions

공개 도메인의 정확한 alias 매핑과 실제 IME·다른 브라우저·영어 검색 검증은 남아 있다. 본문 검색 테스트의 긴 소요 시간은 단계별 성능 측정 없이 원인을 단정하지 않는다.

## Next

후속 구현을 push·배포한 뒤 같은 SHA의 CI와 공개 화면을 다시 확인한다. 새 배포의 이동·pending 동작은 이전 입력 계약 검사와 별도로 기록한다.
