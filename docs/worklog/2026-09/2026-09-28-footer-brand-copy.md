# 푸터의 확인되지 않은 연도와 장식 문구 제거

## Summary

푸터에 고정되어 있던 `© 2024 HEAP-FORGE // PRECISION ENGINEERED` 문구를 제거했다. 확인되지 않은 시작 연도를 현재 연도로 바꾸지 않고, 중복된 브랜드 표기와 장식용 슬로건을 함께 정리했다.

## Changed

- 푸터에는 `HEAP-FORGE` 브랜드명과 보조 링크만 남겼다.
- 한국어와 영어 메시지에서 더 이상 사용하지 않는 `footer.tagline` 키를 제거했다.

## Notes

저작권 표시는 권리 발생의 필수 조건이 아니며, 이 화면에서는 바로 위 브랜드명과 내용을 반복하고 있었다. 구조·공개 계약·컴포넌트 책임 경계는 바뀌지 않아 새 ADR은 작성하지 않았다.
