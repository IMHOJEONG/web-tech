# 이전 현대화 커밋과 카드 hover 모션 후속

## Summary

사용자 요청에 따라 앞선 현대화 소스 3개를 `545428a4`, 정제 기록 6개와 검수 해시를 `082fcb6f`에 커밋했다. 다른 미커밋·공유 목차 항목·외부 스킬·원시 자료를 제외했고 실제 훅이 통과했다. 이후 한 주제씩 진행하는 다음 작업으로 docs 카드 hover 이동·확대의 reduced-motion 대응을 로컬 완료했다.

## Changed

- 실제 소비 중인 카드 5곳의 이동/확대·전환 class 선언만 수정했다. 색상·테두리·키보드 포커스·링크·데이터는 유지한다.
- [검증 보고서](../../verification/accessibility/2026-11-21-card-hover-motion.md)·[정제 증거](../../verification/artifacts/2026-11-21-card-hover-motion.json)와 역할별 목차를 추가했다.
- [KAN-83](https://web-tech-service.atlassian.net/browse/KAN-83)에서 앞선 커밋과 새 후속 작업을 구분한다. 새 카드 변경을 앞선 커밋에 포함한 것으로 보고하지 않는다.

## Notes

- `motion` 가이드를 실제 검색/조회하고 Next 로컬 접근성·기존 모션·ADR 목록을 확인했다. 구조 변경이 없어 새 ADR은 만들지 않는다.
- docs 타입·린트와 세 엔진·세 폭·두 테마·모션 설정의 CSS 변경 전후 비교를 수행했다. 최초 fixture의 grid 부모 누락과 수정은 검증 보고서로 연결한다.
- 기존 사용자 변경·스킬·공통 지침·원시 자료를 보존한다. 새 카드 코드·기록은 로컬 미커밋이며 푸시·PR·배포는 수행하지 않는다.
- 지식 승격 판단: 전환을 끄는 것과 hover 효과의 값 변화를 막는 것을 구분하는 기준을 기존 현대화 지식 v9에 보완하고 본문·근거를 재조회했다. 작업 댓글을 별도 지식 본문 갱신으로 대신하지 않는다.

## Open Questions

실기기·실제 라우트·스크린리더·성능 실측은 이번 CSS 효과 검증 범위 밖이다.

## Next

현재 카드 한 주제의 로컬 적용·검증을 완료했다. 다음 주제는 검색 입력의 포커스·의미 구조 검토이며 이번에 함께 구현하지 않는다. 새 카드 변경은 앞선 두 커밋과 분리한 미커밋 상태다.

## 최종 검증

- 최종 docs 타입·린트·소스 5파일 포맷·diff 검사 통과.
- Chromium·Firefox·WebKit × 세 폭 × 두 테마 × normal/reduce, 전후 72페이지에서 카드 180개 비교 통과. 일반 모션 90개 보존·reduce 90개 제거, 색상·포커스·Enter 180개 보존과 실행 중 설정 변경 90조건을 확인했다.
- 합성 DOM의 실제 grid 문맥 누락·역 Tab의 브라우저 영역 경유·macOS WebKit의 Option-Tab 기본 탐색을 정정하고 판정 조건을 유지했다. 전체 React/Next 라우트·실기기 검증으로 확대하지 않는다.

- 작업 기록: 기존 Confluence 운영 댓글 v3에 두 커밋과 새 카드 작업을 연결하고 재조회했다. 읽기 응답이 붙인 heading id 때문에 첫 저장이 거부돼 기존 본문·링크를 보존한 정규 HTML로 복구했다. 별도 지식 v9는 원래 본문·로컬 원본·Apple 기준 링크·상위 탐색 경로를 확인했다. 공통 지침의 로컬/원격 변경은 없다.
- 마감: 소스5·문서6의 11파일 포맷·diff와 작업 트리 view 문서6개 검사 통과·오류0. 다른 기존2,331개·HEAD·빈 index 보존. 이전 두 커밋은 완료했고 새 카드 변경은 미커밋·미푸시로 유지한다.

## 후속 커밋 준비

사용자가 카드 모션 작업 커밋을 명시적으로 요청했다. 위 미커밋 표시는 최초 적용 마감 시점의 상태다. 검증한 소스 5파일의 해시가 동일함을 다시 확인하고, 관련 정제 기록 6파일과 검수 manifest만 함께 로컬 커밋한다. 공유 목차는 이 주제의 행만 부분 스테이징하며 다른 작업·외부 스킬·원시 자료는 제외한다. 커밋 결과와 새 검색 접근성 점검은 후속 작업 기록에서 연결하며 푸시·배포는 수행하지 않는다.
