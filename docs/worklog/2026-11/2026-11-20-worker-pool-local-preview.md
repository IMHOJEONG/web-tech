# 워커 풀 초안의 로컬 미리보기 재연결

2026-11-21 기록 정리: 아래 초안 상태·실행·서버 유지·발행 결과는 11-20 당시 관측이다. 이번에는 정제 기록만 대조하며 원문·원시 자료를 복사하거나 실험·브라우저·게시·배포를 다시 실행하지 않는다.

## Summary

[KAN-65](https://web-tech-service.atlassian.net/browse/KAN-65)의 기존 워커 풀 초안을 로컬 블로그에서 다시 열었다. 기준 main `c6465f48`. 기존 비공개 보존본에서 해당 파일만 저장소 밖 작업 사본으로 복원했으며 원본 보관소와 다른 글은 수정하지 않았다.

## Changed

- 개발 전용 draft 로더에 선택적 `DOCS_LOCAL_DRAFT_ROOT` 절대 경로를 추가했다. 운영·테스트 모드는 원문 루트를 해석하기 전에 종료하며 공개 목록·검색·사이트맵은 이 변수를 사용하지 않는다.
- [집필 절차](../../runbooks/docs-contributor-guide.md)에 재실행 방법을 추가했다. 개인 경로·초안 원문·원시 결과는 저장소에 복사하지 않았다.
- 127.0.0.1:3001의 개발 서버와 해당 preview 탭을 유지했다. 글은 draft이고 기존 본문·과거 측정 표·도식을 바꾸지 않았다.

## Notes

원문 8개 TS 조각을 조립해 실험실 복제본과 대조하고 strict 타입·실행·HTTP 포화 검사를 수행했다. 세 테스트가 통과했으며 HTTP 요청 40건의 접수 상태·503 조건·거절 이후 새 요청 접수와 부하 종료 뒤 200을 검사했다. 기존 표의 수치는 과거 측정값으로 유지하고 이번 결과로 덮어쓰지 않았다. 기술·초보자 이해·존댓말의 읽기 전용 에이전트 검토에서도 새 문제는 없었다.

로더 회귀 2개, 콘텐츠 회귀 51개 및 6개 문서 작성 검사·node-test 타입·변경 파일 lint를 확인했다. 최초 샌드박스 실행의 loopback EPERM과 제한 해제 후 성공을 구분한다. 의존성 준비가 필요한 상태였고 최초 설치 DNS 제한 뒤 고정 lockfile 설치를 완료했다. lockfile과 manifest 변경은 없다.

실제 로컬 화면에서 본문·두 도식·결과 표가 표시됐고 접힌 목차를 펼쳐 HTTP 절로 이동하는 동작을 확인했다. 실기기·지속 부하·전체 production suite는 미실행이다. 렌더러·제목 ID 계약 변경은 없다.

이번 작업은 기존 개발 전용 미리보기와 실험의 재연결·재검사다. 새 개념이나 운영 판단 기준을 도출하지 않아 별도 지식 페이지는 만들지 않는다. 공통 지침과 ADR의 변경도 없다. [Jira 기존 검증 표](https://web-tech-service.atlassian.net/browse/KAN-65?focusedCommentId=10093)와 [Confluence 운영 안내 댓글](https://web-tech-service.atlassian.net/wiki/pages/65817?focusedCommentId=20054018)에 실행 요약을 연결하고 재조회했다. 이를 지식 문서화 완료로 간주하지 않는다. 작업 기록 갱신만 수행했으며 공통 지침의 로컬·원격 반영은 없다.

## Open Questions

초안은 사용자 검토 대기다. 아래 후속 지시로 원본 작업 위치를 확정했다. 앞선 임시 사본은 백업으로만 보존하며 이후 집필 원본으로 사용하지 않는다.

### 후속: 콘텐츠 폴더를 집필 원본으로 확정

사용자가 추가한 별도 `heap-forge-content` 폴더를 앞으로의 초안·원고 작업 위치로 지정했다. 해당 폴더에 작성 지침을 추가하고 기존 워커 풀 초안을 bytes 변경 없이 옮겼다. 실험실의 원문 바인딩과 개발 서버의 외부 초안 루트를 새 위치로 연결했으며 원문·타입·HTTP 검사 3개를 다시 통과했다.

앱 AGENTS와 기존 집필 절차를 로컬 수정하고 수요일 기고 자동 작업의 작성 위치도 갱신·재조회했다. 일정과 검토·커밋 금지 조건은 유지한다. 콘텐츠 저장소의 검수 목록·published 글과 운영 lock은 변경하지 않았다. 로컬 지침 수정과 앱 자동 작업 설정 저장을 구분하며 Git 원격 반영은 없다. 기존 검토·공개 경계의 경로 확정으로 별도 지식 문서·ADR은 만들지 않는다.

당시 외부 초안 로더·가이드 보완은 별도 미푸시 커밋으로 분리돼 있어 현재 main의 완료 기능으로 표시하지 않는다. 존재하지 않는 가이드 앵커 대신 현행 입구를 연결했다.
