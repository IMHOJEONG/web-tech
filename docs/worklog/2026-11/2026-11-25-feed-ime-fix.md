# Feed 한글 조합 입력 수정

## Summary

사용자 요청에 따라 Feed 검색 입력의 중복 조합을 제품 코드에서 수정했다. 브라우저 조합값은 로컬에 두고 확정 시 검색에 반영한다. [기준선과 수정본 검증](../../verification/performance/2026-11-25-feed-interaction-latency.md#후속-제품-수정-검증)을 연결한다.

## Changed

- Feed 필터 바에 로컬 입력 상태와 조합 경계를 두고 URL이 바뀌면 입력값을 복원한다. 레이블과 입력을 명시적으로 연결했다.
- 기존 검증기에 확정 전 요청0회와 확정 요청1회, 조합 취소, 포커스 이동과 필터의 순차 조작, 서로 다른 검색어의 브라우저 이력 복원을 추가했다.
- 기존 성능 기준선을 보존하고 수정본 정제 증거와 후속 계획을 갱신했다.

## Notes

실제 프런트엔드 프로덕션 빌드와 합성 API로 검사했다. Chromium 조합과 세 엔진 기능 회귀의 구체적인 결과는 검증 보고서에 보관했다. 화면이 좁을 때 조합 확정과 필터 포인터 클릭이 겹치면 위치 이동으로 버튼 클릭이 빠지는 경로도 남겼다. 임시 스크롤 보정안은 효과가 확인되지 않아 제품 변경에서 제외했다.

Modern Web Guidance CLI로 `ime-safe-enter-submit`과 `forms`를 조회했다. 조합 이벤트와 브라우저가 확정한 전체 값을 사용했고 명시적 레이블 연결을 적용했다. 구조·공개 계약 결정은 기존 범위다. 사용자 지침 파일의 로컬/원격 변경은 없다. 수정과 검증 기록은 로컬 작업 트리에 있다.

[KAN-83 작업표](https://web-tech-service.atlassian.net/browse/KAN-83)의 이번 행과 운영 안내 댓글 v4를 재조회했다. [Confluence 지식 v45](https://web-tech-service.atlassian.net/wiki/pages/19464193#입력-반응·검색-완료·조합-입력을-분리해-검증하기)에 동기 입력 상태·전체 확정값·포커스 이탈 기준을 보완했고 본문, 원본 경로, 공식 근거와 상위 탐색 경로를 확인했다. 문서 delta 11파일이 통과했다.

## Open Questions
