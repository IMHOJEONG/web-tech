## Changed

- 보조 탐색 조합을 서버 컴포넌트 `DocsIndexDiscovery`로 분리했다. 같은 문서 배열을 전달받으며 추가 API 요청·클라이언트 상태·새 의존성을 만들지 않았다.
- 중복 문서 수 카드를 제거하고 분류 수·최근 수정은 작은 정의 목록, 분류별 이동은 44px 이상 링크로 정리했다. 한/영 안내와 한국어 메타 표현을 맞췄다.
- `updatedAt` 우선·유효한 `date` 대체 중 최신 날짜를 계산해 게시일 정렬 첫 문서를 최근 수정일로 오해하지 않게 했다.
- 기존 태그·모음 E2E는 새 펼침 진입을 거치되 같은 query·읽기 순서·해제·재로드 검사를 유지한다. native 접힘·키보드·큰 글자·테마 회귀와 모델 검사를 추가했다.
- [정책](../../architecture/docs-search-experience-policy.md#문서-목록-순서와-밀도-보완-검토)·[검증 보고서](../../verification/accessibility/2026-11-20-docs-index-discovery.md)·TODO와 목차를 로컬 갱신했다.

## Notes

최종 브라우저 89개 통과·기존 화면 조건 제외 10개, 라이브러리 375개·타입·lint 통과다. 최초 공용 계약 build 누락, 새 helper의 중첩 summary 선택 오류, 태그 해제 후 기본 접힘에 맞춘 재열기 순서 보완은 보고서에 보존한다. 검사 기준·timeout/retry·기존 assertion은 완화하지 않았다.

생성한 합성 문서 17개·이미지 5개를 bytes 대조 후 정리했고 테스트 서버도 종료됐다. 기존 문서·앱 자산·사용자 미커밋·stash·키·공통 설정·콘텐츠 lock은 변경하지 않았다. 앞선 목차 커밋 2개는 기존 브랜치에 그대로 보존한다. 원시 화면·로그는 저장소 밖이다. 최초 검증 시에는 미커밋이었으며, 이후 사용자가 코드·회귀 11개와 정제 문서 6개만 공개 검수·해시 등록·작업별 커밋하도록 승인했다. 푸시·PR·배포·다음 카드 작업은 이번 커밋 범위에서 제외한다.

기존 ADR-0003의 빠른 인덱스와 ADR-0012의 교집합·읽기 순서 계약을 유지한 표현 개선으로 새 ADR은 추가하지 않는다. 보조 탐색의 접힘 상태는 데이터 선택 상태가 아니라 표시 방식이며, 선택·해제는 숨기지 않는다는 기존 정책을 구체화했다. 새 지식 페이지를 만들지 않고 [Confluence 운영 기록](https://web-tech-service.atlassian.net/wiki/pages/viewpage.action?pageId=65817&focusedCommentId=20119671)에 이유와 원본 정책을 연결하며, 진행 댓글을 지식 문서화 완료로 보고하지 않는다. Jira는 로컬 검증 후 검토 중으로 전환하며 병합·운영 완료와 구분한다.

## Open Questions
