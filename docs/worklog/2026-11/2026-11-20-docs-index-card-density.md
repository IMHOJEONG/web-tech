# 문서 인덱스 카드 간격과 중복 메타 정리

## Summary

사용자가 승인한 보조 탐색 코드·회귀 `64043e2f`와 정제 문서·검수 해시 `6f1851cd`를 로컬 커밋한 뒤, TODO의 3단계를 [KAN-88](https://web-tech-service.atlassian.net/browse/KAN-88)로 분리했다. 이후 사용자가 카드 코드·회귀7개와 정제 문서6개만 공개 검수·해시 등록·작업별 로컬 커밋하도록 승인했고, 코드·회귀는 `35f73bbd`로 커밋했다. 푸시·PR·운영 반영은 아니다.

## Changed

- 제목·요약 글자 크기는 그대로 두고 카드 padding과 내용 사이 간격을 줄였다. 실제 링크·검색 강조·전체 제목 줄바꿈을 보존한다.
- 분류·주제·태그의 정규화 비교와 표시 책임을 순수 모델로 분리했다. 중복 이후 서로 다른 태그 두 개를 선택하고 빈 메타 목록은 생략한다.
- 앱 한정 간격 상수를 카드·서버 스켈레톤에서 공유하고 기존 독립 snapshot 기하 검사에 padding 일치 조건을 추가했다. 공용 UI·실행 중 React DOM을 변경하지 않는다.
- [정책](../../architecture/docs-search-experience-policy.md#3-카드-밀도-검토)·TODO·[검증 보고서](../../verification/accessibility/2026-11-20-docs-index-card-density.md)와 목차를 로컬 갱신했다.

## Notes

모델·라이브러리 381개와 타입·lint가 통과했다. 첫 브라우저 실행은 95개 통과·기존 조건 제외 10개, 기본 간격 명시 검사와 스켈레톤 최종48개도 모두 통과했다. 최초 스켈레톤은 빈 결과에서 첫 카드를 찾던 새 조건으로6개 실패·18개 통과했다. 빈 결과의 제목·기사 없음과 실제 카드의 padding 비교를 구분해 해결했으며 검사 기준·timeout/retry·기존 assertion은 완화하지 않았다. 상세 결과·실패·측정 한계는 보고서에 보존한다.

커밋 전 같은 코드의 라이브러리381개·앱 타입·변경 코드 lint·13개 파일 포맷을 재검사해 통과했다. 브라우저 수치는 앞서 실행한 결과를 보존하며 이번 커밋 단계에서 다시 실행했다고 보고하지 않는다. 원시 자료·합성 입력·다른 작업은 검수·커밋 범위에서 제외한다.

`OPEN` 문구는 기존 코드에 이미 없어 제거했다고 기록하지 않는다. 새 구조 결정 없이 기존 ADR-0003·ADR-0005의 인덱스/공용 카드 책임과 밀도 정책을 구현하므로 새 ADR·지식 페이지를 만들지 않는다. [Confluence 운영 기록](https://web-tech-service.atlassian.net/wiki/pages/viewpage.action?pageId=65817&focusedCommentId=20250681)과 Jira의 3열 표는 별도 지식 문서화 완료와 구분하며 저장 후 재조회했다.

원문·비공개 자료·실제 키·NAS·공통 설정·다른 미커밋·stash는 변경하지 않았다. 신규 합성 문서17개·이미지5개는 생성기 bytes와 대조한 뒤 정리했고 테스트 서버도 종료를 확인했다. 기존 앱 자산은 보존하고 원시 화면·로그는 저장소 밖에 유지한다.
