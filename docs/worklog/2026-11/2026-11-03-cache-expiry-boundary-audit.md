# 캐시 만료 시각 경계 후속 조사

## Summary

KAN-58의 과거 간헐 실패 원인을 더 좁히기 위해 PR #83 병합 후 캐시 시각을 읽기 전용으로 관측했다.
동일 시각의 엄격 비교는 의존성 테스트에서 확인했지만, 실제 요청에서 과거 실패는 재현하지 못했다.
원인을 해결했다고 표시하지 않으며 상세 결과는 [기존 검증 보고서](../../verification/resilience/2026-11-03-docs-sequential-followups.md#pr-83-병합-후-시각-경계-감사)에 이어 기록한다.

사용자가 이번 캐시 계측·회귀 테스트와 정제 문서만 공개 검수하고 커밋하도록 승인했다.
TypeScript 진단·테스트·앱 전용 관측 설정 4개와 운영 문서·목차 5개를 범위로 확정했다.
실제 비밀값·개인정보·내부 주소·개인 경로·서명 URL이 없는 자체 작성 코드·합성 입력·정제 집계임을 확인한다.
원시 trace·로그·이벤트·녹화본·기존 초안은 제외하고 최종 문서 bytes의 SHA-256만 검수 기록에 갱신한다.
재검사 결과는 [보고서 후속 절](../../verification/resilience/2026-11-03-docs-sequential-followups.md#2026-11-06-공개-검수-재확인)에 기록한다.
계측·회귀 4개는 `2f5b1997a5af552912b368e609a1f86e92250fd5`로 분리했으며 문서·검수 해시는 별도 커밋으로 관리한다.
이번 승인은 로컬 커밋까지이며 푸시·PR·main 병합·배포·권한 변경은 실행하지 않는다.

## Open Questions

- 과거 V1/V2 검사와 503 대조군이 최초 이상 상태에 진입한 정확한 요청·캐시 순서는 아직 미확정이다.
- 같은 밀리초 경계나 시계 차이가 실제 실패에 기여했는지 확인할 자연 발생 표본이 없다.
- 이미 확인한 in-flight 늦은 쓰기를 차단할 게시 revision·캐시 세대 계약은 별도 설계 대상이다.

## Next

실패가 다시 발생하면 같은 실행의 요청 순서·캐시 get/set·무효화·origin 버전을 비공개로 대조한다.
누락·저장 실패가 있으면 계측 완결성을 성공으로 인정하지 않는다. 계측 없는 대조 실행도 유지한다.
KAN-58은 원인 미확정 상태로 유지하고 Jira·Confluence에는 정제 결과와 남은 범위만 갱신한다.
후속 후보는 원격 CI 대조와 게시 revision·캐시 세대 설계 실험이다. 늦은 응답 쓰기 차단은 아직 구현하지 않았다.
