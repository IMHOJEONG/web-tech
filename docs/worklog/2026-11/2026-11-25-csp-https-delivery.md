# HTTPS 호환 변경 복원·커밋과 현대화 계획 준비

## Summary

사용자가 HTTPS·WebKit 후속 변경을 커밋한 뒤 다음 Modern Web Guidance 작업을 문서로 정리하도록 요청했다. 앞선 수집기402e2970은 보존됐으나 임시 작업 트리와 미커밋 파일은 사라져 새 관리형 작업 트리에서 복원·재검증했다. 이번 변경은 로컬 커밋 대상이며 푸시·배포하지 않는다.

## Changed

공통 수집기의 WebKit 단일 현대식 envelope 호환, 거절 회귀2개와 재사용 HTTPS 검사기를 복원했다. [새 검증](../../verification/security/2026-11-25-csp-https-delivery.md)·정제 artifact·ADR0038·runbook·목차를 연결한다. 이전 원시 결과를 복원한 것처럼 기록하지 않는다.

## Notes

루트375개(핵심36개)·API 타입/lint·HTTPS12조건을 새로 통과했다. 원본 checkout의51개 변경은 보존했다. 새 의존성/버전/lockfile 변경이 없으며 offline 캐시 부족과 권한 재검사를 검증 보고서에 분리했다. 테스트 서버·브라우저·임시 키/profile은 정리했다.

작업 기록은 KAN-83의 기존3열 표, 지식은 기존 Confluence 주제v42를 원본으로 사용한다. 지식 승격 판단: 새 개념은 앞선 HTTPS 형식/제한 단위 항목과 동일하므로 중복 지식 페이지를 만들지 않고 실제 복원·재검증 상태만 보완한다. 공통 AGENTS 지침의 로컬/원격 변경은 없다. 새 구조 결정이 아닌 기존 ADR0038의 호환 보완으로 처리한다.

## Open Questions

Preview·운영과 플랫폼 실효 제한은 미검증이다. 실제 Safari·실기기와 VoiceOver는 이번에 실행하지 않았다. 사라진 과거 미커밋 파일의 bytes·원시 artifact는 복구하지 못했다.
