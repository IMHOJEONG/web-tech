# 외부 초안 미리보기의 독립 정리

## Summary

미커밋 정리 순서의 두 번째인 개발 전용 외부 초안 미리보기를 [KAN-89](https://web-tech-service.atlassian.net/browse/KAN-89)로 분리했다. 기준 main `2cf837f0`의 새 `codex/docs-external-draft-preview-20261120` 작업 트리에서 원래4개 변경만 재구성하고 회귀와 문서를 보완했다. 이후 사용자가 코드·회귀2개, 앱 지침·가이드2개, 정제 문서·목차4개만 공개 검수·해시 등록·작업별 로컬 커밋하도록 승인했다. 코드·회귀는 `4b1a6b57`로 커밋했으며 원래 checkout은 보존한다. 푸시·운영 반영은 아니다.

## Changed

- `DOCS_LOCAL_DRAFT_ROOT`의 절대 경로를 development의 draft 조회에만 사용한다. production/test는 root를 해석하기 전에 거부하고, 설정이 없으면 기존 root 해석을 유지한다.
- 합성 draft·published·archived, 상대 root·경로 순회·심볼릭 링크와 명시적 인자 우선순위를 검사했다. 공개 목록·검색·사이트맵·release lock은 변경하지 않는다.
- 앱 지침과 기고 가이드에는 원문을 공개 checkout에 복사하지 않는 개발 절차만 보완했다. root 지침·패키지·CI 설정은 바꾸지 않았다.
- [정제 검증 보고서](../../verification/content/2026-11-20-external-draft-preview.md)와 역할별 목차를 추가했다.

## Notes

공용 UI build 후 라이브러리374개·앱 타입·변경 코드 lint가 통과했다. 최초 오프라인 설치·UI 산출물 미준비와 private-git 발행본 없는 부팅 실패는 보고서에 보존한다. 실제로 성공한 브라우저 검사는 legacy 개발 모드의 합성 초안이며 제목·본문·noindex/nofollow·클라이언트 오류0개를 확인했다.

커밋 전 같은 코드의 라이브러리374개·앱 타입·변경 코드 lint와 승인8개 파일의 포맷을 다시 검사해 통과했다. 브라우저 수치는 앞서 실행한 결과이며 이번 커밋 단계에서 재실행했다고 보고하지 않는다. 앱 지침 보완만 승인 범위에 포함하며 root 지침·패키지·CI 설정·실제 초안·원시 자료·키·푸시는 제외한다.

서버를 종료하고 생성 합성 파일을 bytes 대조 후 정리했다. 원문·키·NAS·다른 미커밋·기존 stage·stash는 변경하지 않았다. 이식 중 최신 초안 정책을 과거 파일 전체로 덮어쓰지 않고 해당 기능의 지침만 추가했다.

기존 ADR-0032의 운영 고정 SHA와 ADR-0036의 비공개 초안 작성 결정을 구현하므로 새 ADR은 만들지 않는다. 준비된 발행본과 개발 초안 root의 역할 구분은 기존 정책의 구체화이며 진행 댓글을 새 지식 문서화 완료로 보고하지 않는다.

Jira는 검토 중으로 두고 변경·검증·연결·남은 작업을 3열 표로 기록한다. [Confluence 운영 기록](https://web-tech-service.atlassian.net/wiki/pages/viewpage.action?pageId=65817&focusedCommentId=20217970)에는 정제 조건·결과·한계만 연결한다. 미푸시 커밋의 원격 링크와 원시 자료는 넣지 않는다.

### 2026-11-22 PR 통합 검증

main56739825 기반 codex/docs-draft-pr-20261122에서 기존 승인 커밋만 통합했다. 초안 미리보기2개 원본 커밋의 고유 변경만 통합했다. 앱 작성 지침·기고 절차는 승인된 기존 보완이며 root 공통 지침·운영 콘텐츠 공급 경로·키는 변경하지 않는다. docs test:lib 374개와 node-test 타입 검사를 통과했다. development의 명시적 외부 root와 production/test의 조기 종료·경로/상태 제한을 원문 없는 합성 회귀로 검증한다. 전체 앱 타입·lint와 원격 CI는 각각 구분한다. 상세 조건은 연결된 보고서의 같은 날짜 구역을 따른다. 사용자 승인10개 문서 범위에서만 정제 결과·목차·검수 해시를 보완하고, 원본/미커밋/stash/비공개 자료를 보존한다. 실제 커밋·원격 PR·CI는 Jira/Confluence에서 검증 SHA와 함께 추적하며 main 병합·배포는 하지 않는다.
