# 병합 후 검증 기록의 중복 제거와 통합 준비

## Summary

2026-11-20 KST, [KAN-51](https://web-tech-service.atlassian.net/browse/KAN-51)의 후속 미커밋 분류에 따라 병합 후 기록17개 항목을 main `2cf837f0`과 대조했다. 별도 `codex/docs-postmerge-records-20261120`에서 준비하고 앞선 카드·초안 미리보기·운영 기록 로컬 커밋과 원본7개 작업 트리를 보존한다. 초기 준비 후 사용자가 후보16개와 검수 목록의 공개 검수·작업별 로컬 커밋을 승인했으며 푸시·운영 조치는 제외한다.

## Changed

- 이미 main에 반영된 Production 전환 기록3개는 중복 적용하지 않는다. ADR-0032의 현행 상태·후속 절과 수정 앵커를 유지한다.
- 인증 CI·초안 정책·공개 사본 정리·목차·Hono·Next의 고유 정제 기록과 합성 판정 테스트를 모았다. 목차2개는 최신 main의 다른 링크를 보존한다.
- 불필요한 신규 provider ID·개인 scope를 줄이고 과거 날짜·main SHA·실패/한계를 유지했다. 실제 원문·응답·로그·자격 증명은 옮기지 않았다.
- [통합 검증 보고서](../../verification/integration/2026-11-20-postmerge-records-consolidation.md)에 원본17개와 후보16개의 관계·명령·경계를 기록한다.

## Notes

새 판정4개와 기존6개·strict 타입 검사는 통과했다. 전체 첫 실행의 기존2개 loopback EPERM을 보존하고 같은 코드의 승인 재실행에서308개 모두 통과했다. 문서 읽기 전용 검사 오류0개·공개 승인 요구15개만 남았으며 index는 비어 있다. 원본7곳의17개 파일·HEAD/index/status와 main 목차 링크를 보존했다. 상세 조건·공개 검사·보존 대조는 검증 보고서에 연결한다. 과거 원격 CI·Production 성공은 이 로컬 통합본의 원격 성공이 아니다.

운영 공급·권한·공용 UI 책임의 새 결정이 없어 새 ADR을 만들지 않는다. 공개 기록의 날짜·실패·실제 관측과 현재 검증을 구분하는 기존 정책 적용이며 새 지식 페이지도 강제하지 않는다. 작업 추적은 기존 미커밋 감사의 [Confluence 후속 기록](https://web-tech-service.atlassian.net/wiki/pages/viewpage.action?pageId=65817&focusedCommentId=20250686)과 연결한다.

KAN-51의 기존 댓글10043에 날짜·기준 SHA를 가진3열 표를 추가하고 Confluence 진행 댓글20250686(v2)에 정제 요약만 기록했다. 둘 다 재조회해 기존 본문·표·링크와 후속 내용 보존을 확인했다. 이슈의 이전 완료 이력·공유 범위를 변경하지 않았고 로컬 후보를 원격 문서처럼 링크하지 않았다.

첫 로컬 커밋 `7fd3e23e`는 합성 Next 판정 회귀1개이며 staged 포맷·문서·공개 검사와 메시지 검사·commitlint가 통과했다. 나머지 정제 문서15개와 검수 목록은 다음 커밋으로 분리한다. 두 커밋의 전체 공개 범위는 `pnpm publication:check --base 2cf837f04954d05d5ff409bdec6794ec28fd7f07`, 메시지는 같은 기준의 `commitlint --from ... --to HEAD --verbose`로 확인하고 실제 결과는 같은 Jira 후속 표에서 로컬-only로 추적한다.

### 2026-11-22 PR 통합 검증

main56739825 기반 codex/docs-records-pr-20261122에서 기존 승인 커밋만 통합했다. 운영 기록2개·병합 후 기록2개·워커1개·Atlassian1개 커밋을 정제 기록 PR로 모았다. 원문 발췌가 있는 원본 JSON·원시 자료·NAS 설정은 재업로드하지 않는다. 기존 #69·#70·#72·#73은 원본 추적용으로 유지하며 닫거나 병합하지 않는다. 저장소308개를 실패/skip 없이 통과했고 정상 Brotli 최소 앱에서 Node24.22.1·Nest11.1.19·403·Guard1회·거부 전 해독을 확인했다. 공격/실제 서비스 안전성 검증은 아니며 운영 조회를 수행하지 않는다. 예제 타입 검사와 원격 CI는 각각 구분한다. 상세 조건은 연결된 보고서의 같은 날짜 구역을 따른다. 사용자 승인10개 문서 범위에서만 정제 결과·목차·검수 해시를 보완하고, 원본/미커밋/stash/비공개 자료를 보존한다. 실제 커밋·원격 PR·CI는 Jira/Confluence에서 검증 SHA와 함께 추적하며 main 병합·배포는 하지 않는다.
