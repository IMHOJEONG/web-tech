# 워커 스레드 초안의 콘텐츠 폴더 이전과 재검토

2026-11-21 기록 정리: 아래 초안 상태·실행·서버 유지·발행 결과는 11-20 당시 관측이다. 이번에는 정제 기록만 대조하며 원문·원시 자료를 복사하거나 실험·브라우저·게시·배포를 다시 실행하지 않는다.

## Summary

사용자 요청에 따라 남은 워커 스레드 초안을 별도 콘텐츠 폴더로 옮겨 재검토하고 로컬 블로그에 열었다. [KAN-63](https://web-tech-service.atlassian.net/browse/KAN-63). 커밋·푸시·게시·배포는 하지 않았다.

## Changed

- 원고 보존본을 복원하고 실험실의 실제 MDX 바인딩을 새 경로로 연결했다. 초안의 상태는 draft다. 공개 검수 manifest·발행 lock·기존 published 원고는 변경하지 않았다.
- 새27회 관측으로 표·서론·해석을 맞추고 메인/워커 콜백 흐름도와 루프백 설명, 이미 게시된 다음 워커 풀 글의 연결을 보강했다.
- 포맷 과정의 원문 변경과 표 갱신 누락을 바로잡았다. [검증 보고서](../../verification/content/2026-11-20-worker-thread-draft-review.md)에 최초 실패와 수정 후 결과를 구분했다.

## Notes

실제 원문6조각·strict 타입·TCP 실행2개, 새27회 측정, 초안 직접 형식 검사·콘텐츠51개·두 화면의 목차/도식을 확인했다. 원시 자료·개인 경로·초안 본문을 외부 기록에 첨부하지 않는다.

재사용 교훈인 외부 원고 설정 탐색과 분할 코드 보존 기준은 [Confluence 주제 문서](https://web-tech-service.atlassian.net/wiki/pages/20283395)로 분리했다. 본문·원격 설정 근거·운영 안내 하위 경로를 확인하고 저장소 지식 색인에도 연결한다. 집필 절차는 로컬 보강만 수행했으며 공통 AGENTS·Git 원격 지침 변경은 없다. Jira 기존3열 표와 운영 안내 댓글도 갱신·재조회했으며 KAN-63은 검토 중으로 유지한다. 새 구조 결정이 없어 ADR은 추가하지 않는다.
