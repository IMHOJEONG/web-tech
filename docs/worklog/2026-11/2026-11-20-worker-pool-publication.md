# 워커 풀 원고 검수와 운영 발행

2026-11-21 기록 정리: 아래 초안 상태·실행·서버 유지·발행 결과는 11-20 당시 관측이다. 이번에는 정제 기록만 대조하며 원문·원시 자료를 복사하거나 실험·브라우저·게시·배포를 다시 실행하지 않는다.

## Summary

사용자가 다른 세션의 워커 풀 초안을 찾아 비공개 저장소로 이전하고 검수 후 게시·배포 및 공개 URL·사이트맵 검증을 명시 요청했다. [KAN-65](https://web-tech-service.atlassian.net/browse/KAN-65). 기존 커밋 금지는 이 원고의 게시 범위에서만 해제됐으며 다른 작업은 보존한다.

## Changed

- 다른 세션의 진행 기록과 원고 보존본·현재 콘텐츠 폴더의 SHA-256을 대조했다. 해당 세션에서는 원문을 찾지 못해 게시가 중단돼 있었으며 다른 최신 원문은 없었다.
- 비공개 콘텐츠 원고의 본문은 유지하고 status 및 발행 메타데이터만 변경했다. 사용자 요청과 수행 검수를 근거로 해당 원고 한 편의 해시 기록을 추가했다. 콘텐츠 커밋은 `e07988e9cf6a899d750445b1cf14d7e10d1aca8d`이며 원격 main 반영을 확인했다. 로컬 작성 지침 등 다른 미추적 파일은 포함하지 않았다.
- 별도 앱 작업 트리에서 lock 한 파일만 커밋·푸시했다. [PR #102](https://github.com/IMHOJEONG/web-tech/pull/102), head `a68e888a4273cdc4e13f8f51119a1755675ed5c4`. 기존 앱 작업 트리의 미커밋 파일은 포함하지 않는다.

## Notes

기술 정확성·초보자 이해·존댓말의 다중 검수에서 게시 차단 문제는 없었다. 원문 TS8조각과 복제 코드 대조·strict 타입·HTTP 포화/503/재접수 3개 통과. 실제 발행본 18편·자산15개의 검수 해시·작성 규칙 검사와 Production 빌드 exit0, 본문·표2개·도식2개·목차 대상 누락0을 확인했다. Chromium 1280px·390px에서 HTTP 절 실제 목차 이동 후 제목 위치는 상단 약96px였고 가로 넘침은 없었다. 모바일에서 코드23줄 펼침도 확인했다. 본문 수치는 과거 관측으로 유지한다.

콘텐츠 회귀51개와 렌더러·heading28개 통과. 처음 합성 CLI fixture에 private-git 환경을 상속해 50통과1실패했으며, 합성 검사는 legacy 환경에서 다시 실행했다. 실제 원고 검수·빌드는 private-git 환경에서 별도로 성공했다. 기존 두 글의 placeholder-like warning은 이 원고와 무관하며 유지한다. 원시 응답·화면·실험 로그·개인 경로·키는 저장소 밖에 둔다.

기존 발행 절차를 적용한 작업이므로 새 개념·운영 판단 기준의 지식 승격이나 새 ADR은 없다. 지침의 추가 원격 반영도 이번 발행에 포함하지 않는다. 작업 이력과 지식 문서화를 구분한다. 운영 확인 후 Jira 기존 3열 표와 Confluence 운영 안내 댓글을 갱신·재조회했고 KAN-65를 완료로 전환했다. 새 지식 문서·공통 지침 배포는 없다. 임시 Production 검증 서버만 종료하고 기존 개발 서버와 작업 파일을 유지했다.

## Open Questions

운영 발행 검증은 완료했다. 실제 결과·초기 검사 실패와 한계는 [검증 보고서](../../verification/content/2026-11-20-worker-pool-publication.md)에 분리했다. 실기기·지속 부하·별도 인증 콘텐츠 CI의 활성화는 이번 범위 밖이다. 작업 기록·정제 증거는 로컬-only이며 추가 공개 Git 커밋에 포함하지 않았다.
