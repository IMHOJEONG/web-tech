# UI/UX 카드 검사와 스트리밍 완료 구분

## Summary

PR #109의 데스크톱 카드 재시도 통과를 조사했다. 기존 뉴스레터·버튼 없음 조건을 실제 로딩 골격이 통과하는 것을 확인하고, 완성 본문 준비 검사를 별도로 분리했다. 최초 CI 지연 원인은 미확정이다.

## Changed

UI/UX 완성 main·pending 종료 도우미, 실제 스트림 보류·카드 이동 회귀, 누락/중복/미완성 본문의 음성 대조를 추가했다. 기존 docs 스트림 도우미는 marker 인수로 재사용하되 기존 wrapper·인덱스 회귀를 유지한다. 앱 구현·타임아웃·retry·이미지/레이아웃 기준은 바꾸지 않았다.

## Notes

재현 명령·조건·결과·미검증 범위는 [보고서](../../verification/resilience/2026-11-22-uiux-stream-readiness.md)를 따른다. [KAN-51](https://web-tech-service.atlassian.net/browse/KAN-51)의 통합 후속으로 기록한다. 기존 준비 상태 경계를 검사하는 변경으로 새 ADR은 해당 없음이다. 재사용 교훈은 기존 Confluence 주제와 연결하며 진행 기록을 지식 문서 완료로 대신하지 않는다. 원시 자료·원문·실제 키·다른 미커밋·stash는 보존한다.

## Open Questions

원래 CI의 5초 지연을 만든 호출자는 미확정이며 네트워크나 hydration 장애로 단정하지 않는다.

공개 검수·커밋·푸시 후 #109의 CI를 확인한다. #107 병합 뒤 최신 main과 목차 링크·검수 항목을 보존 병합하고 새 hash·CI를 확인한 뒤 최종 메시지 사전검사로 병합한다. 기록 PR #108도 동일 절차로 처리한다.
