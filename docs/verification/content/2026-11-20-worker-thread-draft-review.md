# 워커 스레드 초안 이전과 로컬 재검증

2026-11-21 기록 정리: 아래 초안 상태·실행·서버 유지·발행 결과는 11-20 당시 관측이다. 이번에는 정제 기록만 대조하며 원문·원시 자료를 복사하거나 실험·브라우저·게시·배포를 다시 실행하지 않는다.

## 대상과 조건

2026-11-20, 앱 HEAD `c6465f48`, 비공개 콘텐츠 HEAD `e07988e`. 새 초안은 `status: draft`이며 미추적 상태로 보존한다. [KAN-63](https://web-tech-service.atlassian.net/browse/KAN-63). Apple M1 Pro·macOS26.6.2·Node.js24.22.1, 계산1억5천만회, 조건별9회·전체27회. 원시 자료는 저장소 밖에 보관한다.

## 재현 방법

보존된 원고 한 파일을 별도 콘텐츠 폴더에 복원하고 실제 MDX 코드 바인딩을 새 경로로 갱신했다. 원문6조각을 두 실행 파일로 조립해 실험실과 토큰을 대조하고 strict 타입·별도 송신 프로세스의 TCP 수신을 검사했다. `worker-delay-runner.mts`로 세 조건의 순서를 순환하며27회 재측정했다. 개인 경로와 전용 명령은 블로그 본문에 넣지 않았다.

외부 초안의 메타데이터·본문 형식을 직접 검사하고 `pnpm --filter docs test:content`를 실행했다. 로컬 preview에서 Chromium1280/390px의 실제 목차 이동·코드 펼침·표와 두 도식·noindex를 확인했다.

## 결과와 증거

- 메인 계산의 첫 수신 중앙값192.1ms, 워커 계산42.1ms. 타이머는191.4ms와20.6ms였다. 계산 중앙값은190.9ms와191.3ms다. 원고의12개 표 셀과 서론·차이 계산을 같은 관측 집합에 대조했다.
- 모든 실행의 수신16,384바이트와 계산18회의 체크섬이 일치했다. 메인9회는 계산 후에, 워커9회는 계산 중에 타이머·첫 수신 콜백이 실행됐다. 이 순서를 일반적 보장으로 확대하지 않았다.
- 최초2개 원문·타입·실행 검사는 통과했으나 외부 기본 포맷 후에는 원문 토큰1개 검사가 실패했다. 같은 과정에서 표 갱신 누락도 다중 검토가 발견했다. 표를 직접 대조해 교체하고 코드6조각을 보존본에서 복원했다. 앱 설정을 명시하고 내장 언어 포맷을 꺼 최종2개 검사를 모두 통과했다. 실패 기준을 완화하지 않았다.
- 초안의 메타데이터·본문 형식·51개 콘텐츠 회귀가 통과했다. 첫 샌드박스의 loopback EPERM은 권한 허용 후 같은 검사로 다시 실행해 구분했다. 기술·독자 이해·존댓말 에이전트 두 명이 수정 후 재검토했고 추가 문제가 없었다.
- 페이지 가로 넘침과 목차 대상 누락0. 제목은 실제 클릭 후 상단 약96px. 모바일 표는 페이지 밖으로 넘치지 않고356px 영역에서576px 내용을 내부 스크롤한다. 코드23줄 펼침도 확인했다. `noindex, nofollow`를 유지했다.
