# ADR-0004: About은 소개에 집중하고 공용 셸을 재사용한다

## 상태와 범위

- 상태: 적용 중
- 대상: docs 앱의 About 본문과 전역 header/footer
- 결정일: 2026-05-08
- 최종 검토: 2026-09-21
- 대체: [ADR-0002](adr-0002-about-us-page-and-shared-footer.md)

## 배경

초기 About 구성에는 문의 폼이 있었지만 실제 문의를 접수하지 않기로 했다. 연락처 입력을 남겨두면 사용자에게 제공하지 않는 기능을 약속하게 된다. 페이지마다 header/footer를 복제하면 전역 내비게이션과 접근성 동작도 갈라진다.

## 결정

About 본문은 소개·분야별 관점·작성자 정보를 담당한다. 문의 폼이나 전송 흐름은 제공하지 않는다. header/footer는 About 내부가 아니라 공용 app shell에서 렌더링한다. About의 시각 구성은 전역 셸을 중복하지 않는 범위에서 조정한다.

## 대안과 영향

- 문의 폼을 시각적으로만 유지하면 향후 구현 여지는 있지만, 동작하지 않는 창구를 사용자에게 노출한다.
- 외부 문의 링크를 별도로 두는 방법도 있었으나 현재 운영 범위에 포함하지 않았다.
- 공용 셸을 유지하면 일관성이 높아지는 대신 About 단독으로 header/footer를 자유롭게 바꾸기는 어렵다.
- 실제 문의 접수 정책이 정해지면 인증·스팸 대응·개인정보 처리를 먼저 검토하고 새 결정으로 기록한다.
