# ADR-0014: 로컬 문서 탐색에서 glob 파서를 제거

## 상태와 범위

- 상태: 적용 중
- 대상: docs의 로컬 카테고리 목록, 검색 인덱스, 빌드 revision 계산
- 결정일: 2026-10-09
- 최종 검토: 2026-10-09
- 로컬 production 빌드와 회귀 검사 완료. NAS·Vercel 배포와 저장소 전체의 `braces` 제거는 미완료.

## 배경

`fast-glob → micromatch → braces`가 docs의 직접 운영 의존성으로 포함되어 있었다. 조사 시점의 registry 최신 `braces`는 3.0.3이며 실제 출시된 패치를 확인하지 못했다. 현재 문서 탐색에는 고정된 `data`, `category` 디렉터리와 `.md`, `.mdx` 확장자만 필요하다. 임의 패턴을 해석하는 파서는 필요하지 않다.

## 결정

Node.js 기본 파일 API로 반복형 디렉터리 탐색기를 구현한다. 카테고리는 기존 allowlist를 통과한 디렉터리의 바로 아래 파일만 읽고, 검색과 revision은 두 고정 루트를 재귀 탐색한다. 경로 문자열을 glob 문법으로 해석하지 않는다.

- 숨김 파일·숨김 디렉터리·심볼릭 링크를 제외한다. 심볼릭 링크인 탐색 루트도 따라가지 않는다.
- 소문자 `.md`, `.mdx` 일반 파일만 선택하고 절대 경로를 정렬한다. 본문 파서, 공개 상태 제외, canonical URL, 날짜 정렬은 기존 책임을 유지한다.
- 디렉터리 부재 `ENOENT`는 건너뛴다. 권한·읽기 오류는 전파하여 실패를 빈 검색 인덱스로 캐시하지 않는다.
- 검색·revision 계산은 같은 파일 목록을 사용한다. revision의 POSIX 상대 경로와 파일 바이트 기반 해시 계약을 유지한다.
- 동기 탐색을 선택했다. 기존 카테고리/설정 로딩도 동기 파일 API를 사용하며 현재 corpus는 18개다. 검색 본문 읽기는 계속 비동기다. 성능 향상을 측정하거나 보장한 결정은 아니다.
- 동적 디렉터리 탐색은 자동 파일 추적만으로 충분하다고 가정하지 않는다. Next 설정에 두 루트의 네 가지 확장자 패턴을 명시하고 production trace에서 실제 문서 포함을 검사한다. 빌드 도구의 glob까지 제거하는 결정은 아니다.
- docs 직접 `fast-glob` 의존성과 해당 catalog 항목만 제거한다. ESLint·ts-loader를 통해 남는 개발 의존성은 별도 패치 추적 대상으로 둔다.

[ADR-0011](adr-0011-local-search-index-cache.md)의 캐시 키·태그·만료 정책은 대체하지 않는다. 파일 발견 구현만 변경한다.

## 대안과 영향

- 미출시 `braces@3.0.4` 강제: 설치 가능한 패치가 아니므로 제외한다.
- 비공식 backport: 검토·출처·유지보수 책임이 추가되므로 이번 범위에서 사용하지 않는다.
- 다른 glob 라이브러리: 범용 패턴 기능이 필요한 때에는 유용하지만 고정 루트 탐색에는 불필요한 파서를 추가한다.
- 비동기 순회 또는 빌드 manifest: 큰 corpus의 이벤트 루프 지연·파일 추적 크기를 측정한 뒤 재검토한다. 현재 동기 탐색을 모든 규모에 일반화하지 않는다.

파일 추적 포함 범위를 넓혀 배포 산출물이 커질 수 있다. 로컬 문서가 크게 증가하면 경로별 추적과 사전 인덱스 생성을 검토한다. 심볼릭 링크 기반 콘텐츠 저장은 이 계약에서 지원하지 않는다. 검사 후 파일 교체까지 방어하는 적대적 파일시스템 보안 경계를 주장하지 않는다.
