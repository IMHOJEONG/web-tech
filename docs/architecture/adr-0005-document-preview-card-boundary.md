# ADR-0005: 문서 미리보기 카드의 재사용 경계

## 상태와 범위

- 상태: 적용 중
- 대상: docs 앱의 feed와 UI/UX 문서 카드, 공용 document entity
- 결정일: 2026-09-21
- 최종 검토: 2026-09-21

## 배경

피드와 UI/UX 목록은 제목·요약·주제·썸네일·작성자 정보를 반복해서 표시한다. 화면마다 같은 링크·포커스·이미지 처리를 따로 만들면 표현이 갈라진다. 반대로 `/docs` 검색 결과와 카테고리 목록까지 동일한 카드로 묶으면 각 화면의 밀도와 강조점이 사라진다.

## 결정

`entities/document/ui/DocumentPreviewCard`는 단일 상세 링크와 공통 메타·썸네일 표시만 담당한다. 피드와 UI/UX 목록에서 사용한다. 제목 단계, 이미지 옵션, 번역된 읽기 시간은 호출 화면이 전달하고, 데이터 조회·필터·큐레이션 순서는 화면별 widget에 남긴다. `/docs`의 검색 강조 카드와 카테고리 목록은 별도 표현을 유지한다.

## 대안과 영향

- 모든 문서 카드의 전체 레이아웃을 하나로 합치면 유지보수 위치는 줄지만 인덱스·큐레이션·분류의 시각적 목적이 희석된다.
- 모든 카드가 독립 구현이면 화면별 자유도는 높지만 접근성·메타 표현을 반복 수정해야 한다.
- 제한적 재사용은 공통 시각 규칙을 공유하면서 화면 책임을 보존한다. 새 화면에서 공통 카드가 맞지 않으면 변형을 늘리기 전에 별도 표현이 필요한지 판단한다.
