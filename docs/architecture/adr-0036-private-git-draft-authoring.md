# ADR-0036: 비공개 콘텐츠 Git을 초안의 기본 작성 위치로 사용

## 상태와 범위

- 상태: 적용 중
- 대상: 블로그 초안·발행 원문·글 전용 자산의 작성 지침
- 결정일: 2026-11-20
- 최종 검토: 2026-11-20
- 적용 위치: 공개 코드·비공개 콘텐츠 저장소의 지침 전용 브랜치에서 검수·PR 준비. main 반영·기존 초안 이전·게시·운영 설정은 별도이며 이번에는 실행하지 않는다.
- 보완: [ADR-0032](adr-0032-private-git-build-content.md)의 고정 발행 입력과 [ADR-0034](adr-0034-content-ci-identity-approval.md)의 사람 승인 경계를 유지한다. 별도 미푸시 자동화 작업의 ADR-0035는 이번 PR에 포함하지 않으며 기존 결정 본문도 바꾸지 않는다.

## 배경

발행 원문은 비공개 Git으로 옮겼지만 초안 지침에는 공개 앱 폴더·로컬 전용 branch와 모든 초안 커밋 금지 문구가 남아 있었다. 다른 세션의 글을 찾거나 작성할 때 원문 위치가 분산되고, 공개 Git의 branch나 draft가 비공개 저장을 보장한다는 오해도 생길 수 있다.

## 결정

새 초안과 발행 원문은 비공개 `IMHOJEONG/heap-forge-content`의 `category/` 또는 기존 `data/`에서 작성한다. 글 전용 이미지는 같은 저장소의 `public/`에 둔다. 제목·작성 상태를 바꿀 때 라우트용 경로를 자동 변경하지 않는다. 별도의 `drafts/` root를 만들지 않는다.

초안은 `status: draft`로 비공개 Git에 저장할 수 있다. 커밋·푸시는 사용자 요청이 있을 때 해당 저장소·파일에 한정한다. 비공개 커밋은 공개 의도 검수·게시 승인을 대신하지 않는다. 사람 검수와 글별 명시적 게시 승인 후에만 `published` 전환·원문/자산 해시 등록·고정 콘텐츠 커밋·release lock PR·사람 병합·배포 검증으로 진행한다.

공개 `web-tech`는 앱·공용 패키지·합성 검사·정제 운영 문서의 작성 위치다. 새 실제 초안·글 자산·원시 자료를 이 checkout으로 복사하지 않는다. 기존 공개 초안·stash·NAS는 별도 승인 전 보존한다. 공개 과거 이력도 재작성하지 않는다.

비밀값·실제 응답·원시 로그·trace·HAR/pcap·원본 캡처·녹화본·DB dump는 비공개 Git에도 저장하지 않는다. 비공개 저장소 접근 권한·키 관리와 글의 public/draft 상태는 별개다. 원격 Preview와 외부 기록에 초안 전문을 올리지 않는다.

## 대안과 영향

- 공개 저장소의 로컬 전용 branch는 실수로 push하면 초안이 공개된다. 새 작성의 기본값으로 사용하지 않고 기존 자료 보존 절차로만 남긴다.
- 별도 로컬 문서 폴더는 안전하게 보관할 수 있지만 세션 간 원문 위치·변경 이력이 분산된다. 글 원문의 기본 위치는 비공개 Git으로 통일하고 비밀값·원시 실험 자료는 별도 제한 공간에 유지한다.
- 현재 private-git 준비기는 draft를 제외하므로 기존 개발 preview route가 원본 비공개 checkout의 초안을 자동 표시하지 않는다. 별도 개발 전용 연결이 필요하며 이 결정으로 구현된 것으로 보고하지 않는다.
- 기존 예약 실행의 프롬프트나 원격 checkout에는 로컬 문서 변경이 즉시 전파되지 않는다. 실제 원격 반영과 예약 지침 점검은 별도 승인·검증 단계다. 이번에 예약·업로드를 새로 만들거나 활성화하지 않는다.
